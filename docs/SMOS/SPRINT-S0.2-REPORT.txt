11. ARCHITECTURAL DECISIONS (ADR)
-----------------------------------
- ADR-010: Meta Architecture (ARCH-010) is the conceptual blueprint of SMOS.
  All documents, agents, and workflows derive from it.
- ADR-011: The Content Lifecycle has 15 mandatory stages. No stage may be
  skipped for published content.
- ADR-012: 14 AI agents follow single-responsibility principle. No agent
  has overlapping responsibilities.
- ADR-013: Automation (n8n) and Agent (AI) are separate layers.
  Agents decide; Automation executes.
- ADR-014: Knowledge is stored in 5 distinct repositories with clear SSOT.
- ADR-015: Human approval is mandatory for: final content publication,
  prompt changes, strategy changes, knowledge base updates, constitution changes.
- ADR-016: Agent-000 (Orchestrator) coordinates all agents but cannot
  produce or approve content.
- ADR-017: The Knowledge Graph is the source of truth for entity relationships.
- ADR-018: Feedback loop runs at 6 different frequencies (daily to annually).

12. RISKS
---------
- RISK-01: 14 agents may be excessive for initial implementation.
  Mitigation: Start with 5 core agents (Orchestrator, Writing, Review,
  Publishing, Analytics) and add incrementally.
- RISK-02: Knowledge Graph may be complex to implement.
  Mitigation: Graph is conceptual; implementation can use relational DB
  or simple tagging initially.
- RISK-03: 15-stage lifecycle may create process overhead.
  Mitigation: Stages are mandatory for published content only. Internal
  drafts can use subset.
- RISK-04: Agent authority matrix requires careful implementation.
  Mitigation: Documented in ARCH-013; implementation must enforce at API level.

13. TECHNICAL DEBT
------------------
- DEBT-01: No implementation of Knowledge Graph (conceptual only).
- DEBT-02: No agent communication protocol defined.
- DEBT-03: No authentication/authorization model for agents.
- DEBT-04: No error handling strategy for inter-agent communication.
- DEBT-05: No SLA or performance targets defined.
- DEBT-06: No disaster recovery for agent/automation systems.
