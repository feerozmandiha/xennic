9. RISKS
--------------------------------------------------------------------------------
  1. Instagram API Limitations (HIGH)
     → Rate limits, Graph API restrictions affect automation
     → Mitigation: Optimized request batching, AUT-IG-* design

  2. Iran Accessibility (HIGH)
     → Instagram banned in Iran — requires VPN
     → Mitigation: Telegram/Bale as primary community platforms

  3. Algorithm Dependency (MEDIUM)
     → Organic reach dependent on Meta algorithm changes
     → Mitigation: Content-quality-first strategy, multi-platform

  4. No Clickable Links in Captions (MEDIUM)
     → Direct traffic to website limited
     → Mitigation: Link in Bio strategy + Story links

  5. AI Visual Generation Quality (MEDIUM)
     → AI-006 graphic output may need human refinement
     → Mitigation: A-2 authority level (human oversight)

  6. CT-ID Drift in Practice (LOW)
     → Content creators may misclassify content
     → Mitigation: AI-004 CT validation gate before publishing
