## ۱. معرفی

این سند معماری کامل سیستم مستندات SMOS را تعریف می‌کند. تمام اسناد آینده باید از این چارچوب پیروی کنند. این سند تابع **قانون اساسی SMOS** (CON-000) است.

## ۲. اهداف معماری

| هدف             | توضیح                                    |
| --------------- | ---------------------------------------- |
| **مقیاس‌پذیری** | پشتیبانی از رشد حداقل ۱۰ ساله            |
| **چندعاملی**    | مناسب انسان، AI Agent، n8n، MCP          |
| **SSOT**        | هر موضوع یک منبع حقیقت واحد              |
| **جداسازی**     | تفکیک استراتژیک، عملیاتی، مرجع، آموزشی   |
| **قابلیت‌یابی** | یافتن سریع هر سند با ID و مسیر استاندارد |

## ۳. طبقه‌بندی اسناد

هر سند SMOS در یکی از ۷ طبقه قرار می‌گیرد:

| طبقه           | توضیح                                 | مثال ماژول                                      |
| -------------- | ------------------------------------- | ----------------------------------------------- |
| **استراتژیک**  | اصول بنیادین، تغییرناپذیر یا کم‌تغییر | CONSTITUTION, ARCHITECTURE, GOVERNANCE          |
| **مرجع**       | اطلاعات فنی، APIها، ابزارها           | REFERENCE                                       |
| **آموزشی**     | راهنمای شروع به کار، آموزش            | TRAINING                                        |
| **پلتفرم**     | کتابچه راهنمای هر پلتفرم              | PLATFORMS, BRAND, EDITORIAL                     |
| **عامل هوش**   | مشخصات فنی Agentها                    | AI-AGENTS                                       |
| **خودکارسازی** | گردش کارهای n8n و اتوماسیون           | AUTOMATION, PROMPTS                             |
| **عملیاتی**    | رویه‌های روزانه، گزارش‌ها، متریک‌ها   | OPERATIONS, REPORTS, METRICS, KNOWLEDGE, ASSETS |
