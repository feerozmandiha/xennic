## ۳. مدل اختیار (Authority Model)

```
                    ┌──────────────────────┐
                    │   Full Human Control  │  ← تصمیمات استراتژیک
                    │   (No AI authority)   │     معماری, قانون اساسی
                    └──────────────────────┘
                                │
                    ┌──────────────────────┐
                    │   Human-Supervised    │  ← تأیید محتوا
                    │   (AI proposes,      │     تغییر پرامپت
                    │    Human disposes)    │     دانش جدید
                    └──────────────────────┘
                                │
                    ┌──────────────────────┐
                    │   Human-on-the-Loop   │  ← تولید محتوا
                    │   (AI acts, Human     │     تحقیق
                    │    monitors)          │     تحلیل
                    └──────────────────────┘
                                │
                    ┌──────────────────────┐
                    │   Full AI Control     │  ← نظارت
                    │   (Pre-approved       │     هشدار
                    │    actions only)      │     جمع‌آوری داده
                    └──────────────────────┘
```

## ۷. قواعد Override

| سناریو       | Override By      | مستندسازی               |
| ------------ | ---------------- | ----------------------- |
| خطای Agent   | انسان (Operator) | CR در Change Management |
| بحران پلتفرم | مدیر رسانه       | گزارش حادثه + ADR       |
| نقض امنیت    | مدیر سیستم       | گزارش امنیتی            |
| ریسک برند    | مدیر برند        | گزارش برند              |
| خطای محتوا   | مدیر محتوا       | اصلاحیه + ADR           |

### مراحل Override

1. شناسایی مشکل توسط انسان یا Agent
2. تأیید نیاز به Override توسط Owner
3. اجرای Override توسط سطح مجاز
4. ثبت در ADR یا Incident Report
5. بررسی علت ریشه‌ای
6. به‌روزرسانی قواعد برای جلوگیری از تکرار

## ۹. ممیزی Agentها (Agent Audit)

هر Agent باید موارد زیر را ثبت کند:

| رویداد              | ثبت                                 | نگهداری |
| ------------------- | ----------------------------------- | ------- |
| هر اقدام (Action)   | timestamp + action + input + output | ۱ سال   |
| هر تصمیم (Decision) | timestamp + decision + reasoning    | ۲ سال   |
| هر خطا (Error)      | timestamp + error + context         | ۱ سال   |
| هر Escalation       | timestamp + reason + response       | ۳ سال   |
| هر Override         | timestamp + authorizer + reason     | ۵ سال   |
| تغییر ریسک          | timestamp + old + new + reason      | ۲ سال   |
