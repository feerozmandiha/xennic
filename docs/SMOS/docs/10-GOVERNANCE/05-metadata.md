## ۱. معرفی

این سند **فراداده (metadata) همه اسناد SMOS** را تعریف می‌کند.
فراداده اطلاعاتی است درباره سند که محتوای اصلی را توصیف می‌کند — نه بخشی از محتوا.

### اهداف

- تسهیل جستجو و کشف اسناد توسط انسان و Agent
- امکان پردازش خودکار اسناد توسط n8n و MCP
- اطمینان از یکپارچگی اطلاعات مدیریتی اسناد
- پشتیبانی از حسابرسی و ردیابی تغییرات

## ۲. فیلدهای فراداده (Metadata Fields)

### ۲.۱ فیلدهای اجباری (Required)

| فیلد        | کلید         | نوع    | توضیح                 | مثال                                                  |
| ----------- | ------------ | ------ | --------------------- | ----------------------------------------------------- |
| عنوان       | title        | string | عنوان فارسی + انگلیسی | `Documentation Standards — استانداردهای مستندات SMOS` |
| شناسه       | id           | string | شناسه یکتای سند       | `GOV-001`                                             |
| وضعیت       | status       | enum   | وضعیت جاری سند        | `پیش‌نویس`                                            |
| نسخه        | version      | string | نسخه semantic         | `1.0.0-draft`                                         |
| به‌روزرسانی | updated      | date   | آخرین تاریخ تغییر     | `2026-06-27`                                          |
| مسئول       | owner        | string | نقش یا فرد مسئول      | `مهندس حکمرانی سازمانی`                               |
| وابستگی     | dependencies | list   | شناسه اسناد وابسته    | `CON-000, ARCH-030`                                   |
| مخاطب       | audience     | set    | مخاطبان هدف           | `human, agent, n8n, mcp`                              |

### ۲.۲ فیلدهای اختیاری (Optional)

| فیلد           | کلید          | نوع    | توضیح                   | مثال                             |
| -------------- | ------------- | ------ | ----------------------- | -------------------------------- |

| تاریخ انقضا    | expires       | date   | تاریخ ازکارافتادن سند   | `2027-06-27`                     |

| ماژول          | module        | string | ماژول مبدأ              | `GOVERNANCE`                     |
| لایه           | layer         | string | لایه معماری             | `L-20`                           |
| جایگزین        | supersedes    | list   | شناسه اسناد جایگزین‌شده | —                                |
| جایگزین‌شده با | superseded_by | list   | شناسه سند جایگزین       | —                                |
| کلمات کلیدی    | keywords      | list   | برای جستجو              | `documentation, writing, format` |

## ۳. محل ذخیره فراداده

همه فیلدهای فراداده در **هدر سند (Frontmatter)** ذخیره می‌شوند — خطوط ابتدایی فایل با فرمت Markdown blockquote:

```markdown
# عنوان سند

> **شناسه:** GOV-001
> **وضعیت:** پیش‌نویس
> **نسخه:** 1.0.0-draft
> ...
```

### ۳.۱ نمایش برای مخاطبان مختلف

| مخاطب | فرمت ترجیحی                | حداقل فیلدهای مورد نیاز       |
| ----- | -------------------------- | ----------------------------- |
| human | هدر فارسی readable         | همه فیلدهای اجباری            |
| agent | هدر ساختاریافته قابل parse | همه فیلدهای اجباری + tags     |
| n8n   | هدر با کلیدهای ثابت        | id, version, status, audience |
| mcp   | هدر با کلیدهای ثابت        | id, version, dependencies     |

## ۴. مقادیر مجاز (Enums)

### ۴.۱ وضعیت (status)

| مقدار       | توضیح                                                       |
| ----------- | ----------------------------------------------------------- |
| پیش‌نویس    | Draft — در حال نگارش، برای Agent قابل دسترسی نیست           |
| منتشرشده    | Published — منبع حقیقت واحد                                 |
| منسوخ       | Deprecated — هنوز معتبر است ولی استفاده از آن توصیه نمی‌شود |
| جایگزین‌شده | Superseded — سند جدید جایگزین شده                           |
| بایگانی     | Archived — فقط خواندنی، غیرقابل تغییر                       |

### ۴.۲ مخاطب (audience)

| مقدار | توضیح                             |
| ----- | --------------------------------- |
| human | انسان — قابلیت خواندن طبیعی فارسی |
| agent | AI Agent — قابلیت پردازش خودکار   |
| n8n   | گردش کار خودکار — قابلیت اجرا     |
| mcp   | MCP Server — قابلیت سرویس‌دهی     |

### ۴.۳ ماژول (module)

ثابت ماژول‌ها طبق [GOV-003](./03-naming-conventions.md):
`CONSTITUTION, ARCHITECTURE, GOVERNANCE, PLATFORMS, BRAND, EDITORIAL, ASSETS, AUTOMATION, PROMPTS, AI-AGENTS, KNOWLEDGE, OPERATIONS, REPORTS, METRICS, REFERENCE, TRAINING, ARCHIVE`

## ۵. اعتبارسنجی فراداده (Metadata Validation)

| قاعده  | توضیح                                                           |
| ------ | --------------------------------------------------------------- |
| VAL-01 | همه فیلدهای اجباری باید پر باشند                                |
| VAL-02 | شناسه باید با الگوی `MODULE-NNN` مطابقت داشته باشد — GOV-003    |
| VAL-03 | نسخه باید با الگوی `X.Y.Z[-suffix]` مطابقت داشته باشد — GOV-002 |
| VAL-04 | تاریخ باید فرمت `YYYY-MM-DD` داشته باشد                         |
| VAL-05 | وضعیت باید یکی از مقادیر مجاز باشد                              |
| VAL-06 | مخاطب باید حداقل شامل `human` باشد                              |
| VAL-07 | ارجاعات وابستگی باید به اسناد Published اشاره کنند — GOV-004    |

## ۶. دسترسی و تغییر فراداده

| فیلد          | چه کسی می‌تواند تنظیم کند | چه کسی می‌تواند تغییر دهد  |
| ------------- | ------------------------- | -------------------------- |
| title         | Maintainer                | Owner                      |
| id            | Owner (فقط در Proposal)   | هیچ‌کس (تغییرناپذیر)       |
| status        | Maintainer                | Reviewr, Approver          |
| version       | Maintainer                | Maintainer                 |
| updated       | سیستم / Maintainer        | Maintainer                 |
| owner         | Owner                     | Custodian (با تأیید Owner) |
| dependencies  | Maintainer                | Reviewer                   |
| audience      | Maintainer                | Owner                      |
| tags          | Maintainer                | Custodian                  |
| supersedes    | Owner                     | Owner                      |
| superseded_by | Owner                     | Owner                      |

## ۷. فراداده در وضعیت‌های مختلف سند

| وضعیت      | فیلدهای اجباری           | فیلدهای قابل تغییر                  | یادداشت                   |
| ---------- | ------------------------ | ----------------------------------- | ------------------------- |
| Proposal   | title, id, status, owner | همه                                 | id موقت است               |
| Draft      | همه اجباری               | title, dependencies, audience, tags | —                         |
| Review     | همه اجباری               | —                                   | فقط Reviewer تغییر می‌دهد |
| Published  | همه اجباری + created     | version, updated                    | محتوا قفل است             |
| Deprecated | همه اجباری               | superseded_by                       | فقط اعلام انسوخ           |
| Superseded | همه اجباری               | superseded_by                       | فقط هدایت به جایگزین      |
| Archived   | همه اجباری               | —                                   | کاملاً قفل                |

## ۹. تطابق

- Maintainer هر سند مسئول صحت فراداده آن است
- Reviewer بررسی می‌کند که فراداده با محتوای سند تطابق دارد
- اسناد با فراداده ناقص نمی‌توانند به وضعیت Published برسند
- اسناد قدیمی باید در بازبینی بعدی فراداده خود را تکمیل کنند
