## ۱. Purpose — هدف

این سند چک‌لیست جامع کیفیت محتوا برای تیم محتوای Xennic است. هر قطعه محتوا پیش از انتشار باید تمام بندهای این چک‌لیست را طی کند.

این سند معماری نیست — ابزار اجرای روزانه بازبینی کیفیت است.

## ۵. Pre-Review Checklist — چک‌لیست پیش از بازبینی

قبل از ارسال محتوا برای بازبینی ویراستار, نویسنده موظف است:

- [ ] عنوان واضح و جذاب است
- [ ] هدف محتوا در brief رعایت شده
- [ ] مخاطب هدف مشخص است و محتوا برای او نوشته شده
- [ ] تمام بخش‌های مورد انتظار وجود دارند
- [ ] حجم محتوا در محدوده تعیین‌شده (±۱۰٪)
- [ ] پاراگراف‌ها کوتاه و خوانا هستند (حداکثر ۴ خط)
- [ ] از فهرست مطالب یا ساختار سلسله‌مراتبی استفاده شده
- [ ] CTA مشخص وجود دارد
- [ ] منابع ذکر شده‌اند
- [ ] محتوا با فرمت درست ذخیره شده

## ۱۸. Final Approval Checklist — چک‌لیست تأیید نهایی

پیش از ارسال برای تأیید نهایی مدیر عملیات:

- [ ] تمام چک‌لیست‌های بالا تکمیل شده‌اند
- [ ] امتیاز نهایی ≥۸۰ محاسبه شده
- [ ] تمام موارد مردود اصلاح شده‌اند
- [ ] نسخه نهایی با نام فایل استاندارد ذخیره شده
- [ ] متادیتای محتوا تکمیل شده (نویسنده, تاریخ, پلتفرم, CTA)
- [ ] فایل‌های پیوست در پوشه مخصوص قرار گرفته‌اند
- [ ] فرم انتشار (OPS-016) آماده شده
- [ ] تقویم تحریریه به‌روز شده
- [ ] مدیر تولید وضعیت را تأیید کرده

### مراحل تأیید نهایی

```
تکمیل چک‌لیست‌ها → محاسبه امتیاز → اصلاح موارد مردود → بازبینی مجدد → تأیید مدیر تولید → تأیید مدیر عملیات → تحویل برای انتشار
```

## ۲۰. Quality Failure Escalation — ارجاع در صورت شکست کیفیت

### مسیر ارجاع

```
نویسنده (اصلاح) → ویراستار (بازبینی) → مدیر تولید (تصمیم) → مدیر عملیات (ارجاع نهایی)
```

### تصمیم‌نامه ارجاع

| تعداد دفعات شکست | اقدام                                       |
| ---------------- | ------------------------------------------- |
| اول              | بازگشت به نویسنده + راهنمایی ویراستار       |
| دوم              | بازگشت به نویسنده + جلسه آموزشی با ویراستار |
| سوم              | تغییر نویسنده یا بازبینی فرآیند تولید       |
| چهارم و بیشتر    | جلسه فوری مدیر عملیات + بازبینی کامل فرآیند |

### شرایط ارجاع فوری

| وضعیت                                | اقدام                                    |
| ------------------------------------ | ---------------------------------------- |
| خطای حیاتی (اطلاعات نادرست منتشرشده) | توقف فوری + اصلاح + گزارش به مدیر عملیات |
| عدم انطباق حقوقی                     | توقف فوری + مشورت حقوقی                  |
| شکایت ذی‌نفع                         | پاسخ در ≤۲ ساعت + جلسه فوری              |
