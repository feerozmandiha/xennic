## ۱. Purpose — هدف

این سند راهنمای عملیات روزانه اعمال صدای برند Xennic در تمام محتواها است. هر آنچه یک نویسنده یا ویراستار برای نگارش محتوای منطبق با صدای برند نیاز دارد در این سند تعریف شده است.

این سند معماری نیست — دستورالعمل نگارش روزانه است.

## ۳. Brand Voice Principles — اصول صدای برند (خلاصه عملیاتی)

### چهار ستون صدای Xennic

| ستون            | توضیح                     | عملیاتی                                           |
| --------------- | ------------------------- | ------------------------------------------------- |
| **قابل اعتماد** | اطلاعات دقیق, منابع معتبر | هر ادعا با داده یا منبع تأیید شود                 |
| **حرفه‌ای**     | زبان رسمی ولی صمیمی       | بدون اصطلاحات عامیانه, بدون شوخی نامناسب          |
| **نوآورانه**    | نگاه به آینده, ذوق فناوری | استفاده از واژه‌های پویا, جملات کوتاه و تأثیرگذار |
| **انسان‌محور**  | درک نیاز مخاطب, همدلی     | زبان ساده, اجتناب از اصطلاحات فنی پیچیده          |

### قاعده طلایی صدا

> **اگر یک مشتری بالقوه این محتوا را بخواند, آیا احساس اعتماد و احترام می‌کند؟** اگر پاسخ خیر است, بازنویسی کن.

## ۴. Writing Style Checklist — چک‌لیست سبک نگارش روزانه

### قبل از شروع نگارش

- [ ] موضوع و مخاطب محتوا مشخص است
- [ ] پلتفرم هدف مشخص است (لحن متفاوت)
- [ ] نوع محتوا مشخص است (مقاله, پست, ویدئو و...)
- [ ] CTA مورد نظر مشخص است

### حین نگارش

- [ ] جملات کوتاه و واضح (حداکثر ۲۵ کلمه)
- [ ] یک ایده در هر پاراگراف
- [ ] پاراگراف‌های کوتاه (حداکثر ۴ خط)
- [ ] استفاده از لیست‌ها و جداول برای اطلاعات
- [ ] اجتناب از جملات منفی (به جای "ما مشکل را حل نمی‌کنیم" → "ما راه‌حل ارائه می‌دهیم")
- [ ] استفاده از فعل‌های فعال (به جای "گزارش تهیه شد" → "ما گزارش تهیه کردیم")

### بعد از نگارش

- [ ] چک‌لیست صدای برند (بخش ۱۴) تکمیل شده
- [ ] املای محتوا بررسی شده
- [ ] لینک‌ها و منابع تأیید شده
- [ ] بازبینی توسط ویراستار انجام شده

## ۵. Tone Adjustments per Platform — تنظیم لحن بر اساس پلتفرم

### جدول لحن پلتفرم‌ها

| پلتفرم          | لحن              | رسمیت | مثال                                 |
| --------------- | ---------------- | ----- | ------------------------------------ |
| **لینکدین**     | حرفه‌ای, تحلیلی  | بالا  | "گزارش Q۲ نشان می‌دهد که..."         |
| **اینستاگرام**  | صمیمی, بصری      | متوسط | "باورت میشه این قابلیت جدید..."      |
| **تلگرام**      | خبری, مختصر      | متوسط | "خبر فوری: به‌روزرسانی جدید..."      |
| **بله**         | خبری, رسمی       | بالا  | "اطلاعیه رسمی: ..."                  |
| **ایکس/توییتر** | کوتاه, تأثیرگذار | کم    | "یک خبر مهم برایتان داریم..."        |
| **یوتیوب**      | آموزشی, روایی    | متوسط | "در این ویدئو با هم یاد می‌گیریم..." |

| **وبسایت**      | حرفه‌ای, جامع    | بالا  | "Xennic با هدف ارائه راه‌حل‌های..."  |

### قاعده تنظیم لحن

> **لحن ثابت, شدت متغیر.** هسته صدای برند در همه پلتفرم‌ها یکسان است ولی شدت رسمیت و صمیمیت متفاوت است.

## ۸. Persian Language Style Guidelines — قواعد سبک زبان فارسی

### قواعد نگارش فارسی

| قاعده       | توضیح                   | مثال درست             | مثال نادرست            |
| ----------- | ----------------------- | --------------------- | ---------------------- |
| نیم‌فاصله   | بین پیشوند/پسوند و کلمه | برنامه‌ریزی           | برنامه ریزی            |
| فاصله مجاز  | بین کلمات               | مدیریت محتوا          | مدیریتمحتوا            |
| نشانه گذاری | انتهای جمله نقطه        | مدیریت محتوا.         | مدیریت محتوا           |
| عدد فارسی   | در متن فارسی            | ۱۲۳                   | 123                    |
| عدد انگلیسی | در اصطلاحات فنی         | Q2, API               | Q۲, ای‌پی‌آی           |
| ویرگول      | بین اجزای لیست          | هوش مصنوعی, اتوماسیون | هوش مصنوعی و اتوماسیون |
| نقل قول     | گیومه فارسی             | «مدیریت محتوا»        | "مدیریت محتوا"         |

### ساختار جمله فارسی

| قاعده       | توضیح                                |
| ----------- | ------------------------------------ |
| ترتیب کلمات | فاعل + مفعول + فعل                   |
| طول جمله    | حداکثر ۲۵ کلمه                       |
| پاراگراف    | حداکثر ۴ خط                          |
| لیست        | استفاده از bullet point برای ≥۳ مورد |
| عنوان       | کوتاه, گویا, بدون علامت سؤال اضافی   |

## ۱۰. Headline Writing Standards — استانداردهای عنوان‌نویسی

### انواع عنوان

| نوع        | کاربرد               | ویژگی                |
| ---------- | -------------------- | -------------------- |
| عنوان اصلی | مقاله, پست اصلی      | ≤۱۰ کلمه, واضح, جذاب |
| عنوان فرعی | زیرمجموعه عنوان اصلی | ≤۸ کلمه, توضیحی      |
| CTA        | دعوت به اقدام        | ≤۵ کلمه, عمل‌محور    |
| عنوان لیست | پست‌های لیستی        | عدد + کلمه کلیدی     |

### فرمول‌های عنوان‌نویسی

| فرمول                 | مثال                                        |
| --------------------- | ------------------------------------------- |
| عدد + موضوع + نتیجه   | ۵ راهکار برای افزایش بهره‌وری               |
| چگونه + موضوع + نتیجه | چگونه مدیریت محتوا را متحول کنید            |
| سؤال + مخاطب          | آیا تیم شما هم این مشکل را دارد؟            |
| دستور + موضوع         | همین الان استراتژی محتوای خود را بهینه کنید |

### چک‌لیست عنوان

- [ ] حداکثر ۱۰ کلمه
- [ ] حاوی کلمه کلیدی اصلی
- [ ] واضح و بدون ابهام
- [ ] جذاب برای مخاطب هدف
- [ ] بدون کلمات ممنوع (بخش ۷)
- [ ] مناسب پلتفرم هدف

## ۱۵. Voice Compliance Review Process — فرآیند بازبینی انطباق صدا

### مراحل بازبینی

```
بازبینی خودکار (نویسنده) → بازبینی ویراستار → اعمال اصلاحات → تأیید نهایی
```

### نقش‌ها در بازبینی

| مرحله          | بازبین        | مسئولیت                   |
| -------------- | ------------- | ------------------------- |
| بازبینی خودکار | نویسنده       | تکمیل چک‌لیست صدا         |
| بازبینی اولیه  | ویراستار      | بررسی انطباق با صدای برند |
| اصلاحات        | نویسنده       | اعمال بازخورد ویراستار    |
| تأیید نهایی    | ویراستار ارشد | تأیید نهایی انطباق        |

### معیارهای رد محتوا

| معیار                 | شرایط رد                               |
| --------------------- | -------------------------------------- |
| استفاده از کلمه ممنوع | هر کلمه از بخش ۷                       |
| لحن نامناسب پلتفرم    | رسمی در اینستاگرام, عامیانه در لینکدین |
| جملات بلند            | >۲۵ کلمه در بیش از ۳۰٪ جملات           |
| CTA نامناسب           | CTA نامرتبط با محتوا                   |
| نگارش فارسی اشتباه    | >۳ خطا در نگارش                        |

## ۱۶. Brand Voice Reference Examples — نمونه‌های مرجع صدای برند

### نمونه پست اینستاگرام (صمیمی)

> باورت میشه با یک پلتفرم ساده می‌تونی کل محتوای شبکه‌های اجتماعیت رو مدیریت کنی؟
>
> Xennic اینجاست تا بهره‌وری تیمت رو ۳ برابر کنه.
>
> همین الان دموی رایگان رو امتحان کن 👇

### نمونه پست لینکدین (حرفه‌ای)

> بر اساس گزارش Q۲ ۲۰۲۶, سازمان‌هایی که از اتوماسیون مدیریت محتوا استفاده می‌کنند, ۴۵٪ بهره‌وری بیشتری در تولید محتوا دارند.
>
> Xennic با ترکیب هوش مصنوعی و مدیریت یکپارچه, راه‌حلی برای این چالش ارائه می‌دهد.
>
> برای اطلاعات بیشتر, لینک را در کامنت ببینید.

### نمونه مقاله وبسایت (حرفه‌ای, جامع)

> **مدیریت محتوا در عصر هوش مصنوعی**
>
> در دنیای امروز, مدیریت مؤثر محتوا یکی از چالش‌های اصلی سازمان‌هاست. Xennic با رویکردی نوآورانه, این چالش را به فرصت تبدیل کرده است.
>
> در این مقاله, با اصول مدیریت هوشمند محتوا و نقش هوش مصنوعی در بهینه‌سازی فرآیندها آشنا می‌شوید.

## ۲۰. Outputs — خروجی‌ها

- محتوای منطبق با صدای برند
- گزارش ممیزی ماهانه صدا
- لیست به‌روزرسانی کلمات مجاز/ممنوع
- پیشنهادات بهبود فرآیند نگارش
- نمونه‌های مرجع جدید
