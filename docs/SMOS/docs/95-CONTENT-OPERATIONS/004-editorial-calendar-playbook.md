> **شناسه:** OPS-004
> **نسخه:** 1.0.0-draft

## ۱. Purpose — هدف

این سند راهنمای عملیات روزانه مدیریت تقویم تحریریه Xennic است. تقویم تحریریه قلب تپنده عملیات محتواست — هر آنچه تولید, بازبینی و انتشار می‌شود از این تقویم مدیریت می‌شود.

این سند معماری نیست — دستورالعمل استفاده روزانه از تقویم تحریریه است.

## ۵. Priority Assignment — تعیین اولویت

### سطوح اولویت

| اولویت     | توصیف                  | مهلت تولید | مهلت بازبینی |
| ---------- | ---------------------- | ---------- | ------------ |
| P1 — فوری  | بحرانی, رویداد فوری    | ≤۲۴ ساعت   | ≤۴ ساعت      |
| P2 — بالا  | مهم, کمپین فعال        | ≤۳ روز     | ≤۱ روز       |
| P3 — متوسط | عادی, برنامه‌ریزی‌شده  | ≤۵ روز     | ≤۲ روز       |
| P4 — پایین | Evergreen, انعطاف‌پذیر | ≤۱۰ روز    | ≤۳ روز       |

### جدول تصمیم اولویت

| معیار                  | P1        | P2       | P3         | P4           |
| ---------------------- | --------- | -------- | ---------- | ------------ |
| هم‌راستایی با استراتژی | حیاتی     | مهم      | مرتبط      | کم‌ارتباط    |
| پتانسیل تعامل          | خیلی بالا | بالا     | متوسط      | پایین        |
| فوریت زمانی            | فوری      | <۱ هفته  | <۱ ماه     | بدون محدودیت |
| وابستگی به رویداد      | این روز   | این هفته | این ماه    | ندارد        |
| پشتیبانی KPI           | KPI اصلی  | KPI فرعی | KPI ثانویه | ندارد        |

### قوانین اولویت

1. **P1 بدون استثنا**: هر محتوای P1 جایگزین محتوای پایین‌تر می‌شود
2. **حداکثر ۲ محتوای P1 در هفته**: در غیر این صورت بازتخصیص منابع
3. **P4 فقط در صورت ظرفیت خالی**: اگر ظرفیت تیم تکمیل باشد, P4 کنار گذاشته شود
4. **بازبینی اولویت هفتگی**: هر شنبه اولویت‌ها بازبینی می‌شوند

## ۱۳. Version Control for Calendar — کنترل نسخه تقویم

### قوانین نسخه‌بندی

1. **هر تغییر ثبت شود**: افزودن, حذف, تغییر زمان, تغییر وضعیت
2. **نسخه هفتگی**: هر شنبه نسخه جدید از تقویم ذخیره شود
3. **بازگشت‌پذیری**: امکان بازگرداندن تغییرات قبلی
4. **مشاهده‌پذیری**: تاریخچه تغییرات برای همه قابل مشاهده

### ثبت تغییرات

| نوع تغییر    | فرمت ثبت                             | مسئول      |
| ------------ | ------------------------------------ | ---------- |
| افزودن موضوع | [+عنوان] در [تاریخ]                  | مدیر تولید |
| حذف موضوع    | [-عنوان] در [تاریخ]                  | مدیر تولید |
| تغییر زمان   | [عنوان]: [تاریخ قدیم]→[تاریخ جدید]   | مدیر تولید |
| تغییر وضعیت  | [عنوان]: [وضعیت قدیم]→[وضعیت جدید]   | مسئول      |
| تغییر اولویت | [عنوان]: [اولویت قدیم]→[اولویت جدید] | مدیر تولید |
