## Architectural Dependencies

### Why This Document Exists

BRD-001 معماری هویت برند Xennic را تعریف می‌کند — **کیستی** برند. BRD-002 معماری ارتباط کلامی برند را تعریف می‌کند — **چگونگی گفتار** برند. بدون این سند:

- هر نویسنده، مهندس و Agent صدای متفاوتی از برند تولید می‌کند
- ساختار جملات، پاراگراف‌ها و تیترها بدون قاعده است
- نحوه روایت، داستان‌سرایی و اقناع در سطوح مختلف مخاطب ناشناخته است
- نحوه نوشتن برای مخاطب عمومی، متخصص، مدیر اجرایی و بحران متفاوت و ناپایدار است
- هیچ Agent هوشمندی نمی‌تواند سبک نوشتار برند را بدون ابهام یاد بگیرد

این سند **SSOT** معماری ارتباط کلامی برند Xennic است. هیچ قاعده ارتباطی در هیچ سند دیگری تعریف نمی‌شود.

### Explicit Scope

این سند فقط تعریف می‌کند:

- معماری صدای برند — Voice و Tone
- معماری زبان — مدل زبانی، سطوح واژگان، اصطلاحات
- معماری نوشتار — جمله، پاراگراف، تیتر
- معماری روایت — داستان‌سرایی، پیام، لایه‌های ارتباطی
- معماری تطبیق — اقتباس برای مخاطب، زمینه و نقش
- معماری کیفیت و حکمرانی — اعتبارسنجی، گیت‌ها، بازبینی

## ۱. Brand Voice

صدای برند **چگونگی بیان** هویت برند است. از [BRD-001 §۱۰](10-brand-identity.md#۱۰-brand-voice) مشتق شده است. Voice در تمام پلتفرم‌ها و قالب‌ها **ثابت** است. Tone تغییر می‌کند، Voice نه.

### ۱.۱ ابعاد Voice

| بعد                         | کمینه     | بیشینه | پیش‌فرض | DNA  |
| --------------------------- | --------- | ------ | ------- | ---- |
| **آگاهانه** (Knowledgeable) | عمومی     | تخصصی  | ۷۰٪     | نور  |
| **صریح** (Direct)           | غیرمستقیم | مستقیم | ۸۰٪     | نیرو |
| **محترم** (Respectful)      | غیررسمی   | رسمی   | ۷۵٪     | نور  |
| **الهام‌بخش** (Inspiring)   | واقع‌گرا  | آرمانی | ۶۰٪     | یکتا |
| **انسانی** (Human)          | خنثی      | گرم    | ۷۰٪     | یکتا |

### ۱.۲ قواعد Voice

| ID       | قاعده                                                        |
| -------- | ------------------------------------------------------------ |
| VOICE-01 | هر ۵ بعد در هر قطعه ≥ ۵۰ کلمه قابل تشخیص باشند               |
| VOICE-02 | انحراف > ۳۰٪ از وزن پیش‌فرض نیازمند توجیه مستند              |
| VOICE-03 | Voice در همه پلتفرم‌ها یکسان — Tone تغییر می‌کند             |
| VOICE-04 | Voice توسط AI-003 قابل تولید و توسط AI-004 قابل ارزیابی باشد |
| VOICE-05 | Voice تابع DNA است: نور→آگاهانه, نیرو→صریح, یکتا→انسانی      |

## ۴. Writing Principles

اصول بنیادین نوشتار برند — برای انسان و Agent الزامی است.

### ۴.۱ اصول بنیادین

| ID    | اصل                     | توضیح                                                 |
| ----- | ----------------------- | ----------------------------------------------------- |
| WR-01 | **یک جمله، یک ایده**    | جملات مرکب طولانی > ۳۰ کلمه ممنوع                     |
| WR-02 | **ایجاز**               | حذف واژگان زائد — کم‌گویی پرمعنا                      |
| WR-03 | **فعل در پایان**        | ساختار دستوری SOV فارسی حفظ شود                       |
| WR-04 | **معلوم به جای مجهول**  | "تیم تحلیل کرد" نه "توسط تیم تحلیل شد"                |
| WR-05 | **ایجاب به جای احتمال** | "این است" نه "می‌تواند باشد" — مگر در عدم قطعیت واقعی |
| WR-06 | **مثبت به جای منفی**    | "موفقیت" نه "شکست‌ناپذیری"                            |
| WR-07 | **مشخص به جای کلی**     | "۲۴٪ رشد" نه "رشد قابل توجه"                          |
| WR-08 | **منبع‌دار**            | ادعا بدون منبع ممنوع                                  |

### ۴.۲ اصول ساختاری

| ID     | اصل                 | توضیح                                               |
| ------ | ------------------- | --------------------------------------------------- |
| WR-S01 | **هرم وارونه**      | مهم‌ترین اطلاعات در ابتدا                           |
| WR-S02 | **تیتر خبری**       | تیتر محتوای اصلی را منتقل کند — تیتر کلیشه‌ای ممنوع |
| WR-S03 | **زیرتیتر ساختاری** | اسکن محتوا را آسان کند                              |
| WR-S04 | **لیست برای داده**  | اطلاعات قابل شمارش در لیست/جدول                     |
| WR-S05 | **CTA مشخص**        | هر محتوای > ۵۰ کلمه CTA داشته باشد                  |

### ۴.۳ اصول انسانی

| ID     | اصل                               | توضیح                              |
| ------ | --------------------------------- | ---------------------------------- |
| WR-H01 | **مخاطب را مخاطب قرار بده**       | "شما" به جای "کاربران"             |
| WR-H02 | **با مخاطب حرف بزن نه درباره او** | دوم شخص به جای سوم شخص             |
| WR-H03 | **نادرستی را بپذیر**              | "نمی‌دانیم" بهتر از حدس بدون اعلام |
| WR-H04 | **تکبر ممنوع**                    | لحن "ما بهتر می‌دانیم" ممنوع       |

## ۶. Storytelling Architecture

معماری داستان‌سرایی — قواعد روایت داستان در برند.

### ۶.۱ ارکان داستان

| رکن        | توضیح                            | الزام     |
| ---------- | -------------------------------- | --------- |
| **قهرمان** | مخاطب قهرمان است — Xennic راهنما | اجباری    |
| **مسئله**  | تعارض یا چالش                    | اجباری    |
| **تغییر**  | تحولی که رخ می‌دهد               | اجباری    |
| **درس**    | Insight یا یادگیری               | اجباری    |
| **زمان**   | بازه زمانی مشخص                  | توصیه‌شده |

### ۶.۲ قواعد داستان

| ID       | قاعده                                                |
| -------- | ---------------------------------------------------- |
| STORY-01 | داستان واقعی و اصیل — داستان ساختگی ممنوع            |
| STORY-02 | بدون تعارض، داستانی نیست — چالش را شفاف بگویید       |
| STORY-03 | داستان ≤ ۳۰۰ کلمه برای محتوای کوتاه                  |
| STORY-04 | داستان با درس یا Insight پایان می‌یابد               |

### ۶.۳ ساختار روایت

```
وضعیت اولیه (مخاطب کجاست)
    ↓
مسئله یا چالش (مخاطب با چه مواجه است)
    ↓
مداخله (Xennic چه کمکی می‌کند)
    ↓
تغییر (چه تغییری رخ داد)
    ↓
درس یا Insight (مخاطب چه یاد می‌گیرد)
```

## ۱۴. Sentence Architecture

معماری جمله — ساختار، انواع و قواعد جملات برند.

### ۱۴.۱ انواع جمله

| نوع             | شناسه | ساختار               | کاربرد        | حداکثر طول |
| --------------- | ----- | -------------------- | ------------- | ---------- |
| **خبری مستقیم** | ST-DC | فاعل + فعل + مفعول   | خبر، اطلاعیه  | ۲۰ کلمه    |
| **توضیحی**      | ST-EX | موضوع + توصیف + مثال | آموزش، تحلیل  | ۳۰ کلمه    |
| **پرسشی**       | ST-Q  | کلمه پرسش + بدنه     | تعامل، چالش   | ۱۵ کلمه    |

| **شرطی**        | ST-CN | اگر + شرط + نتیجه    | تحلیل، سناریو | ۳۰ کلمه    |
| **نقل قولی**    | ST-QT | منبع + "نقل" + نتیجه | شاهد، اعتبار  | ۲۵ کلمه    |

### ۱۴.۲ قواعد جمله

| ID    | قاعده                                                                  |
| ----- | ---------------------------------------------------------------------- |

| ST-02 | فعل در پایان — ساختار SOV فارسی حفظ شود                                |
| ST-03 | فاعل در ابتدا — مخاطب بداند چه کسی چه می‌کند                           |
| ST-04 | جمله خبری (ST-DC) غالب — > ۶۰٪ جملات در محتوای غیرتعاملی               |
| ST-05 | جملات پرسشی ≤ ۲۰٪ در محتوای غیرتعاملی                                  |
| ST-06 | جملات امری فقط برای CTA و دستورالعمل                                   |
| ST-07 | جملات معترضه (inside — dashes) ممنوع — مطلب را به جمله مجزا منتقل کنید |

### ۱۴.۳ الگوهای جمله ترجیحی

| زمینه      | الگوی ترجیحی            | مثال                                            |
| ---------- | ----------------------- | ----------------------------------------------- |

| **CTA**    | [فعل امر] + [مکمل]      | "همین حالا عضو شوید"                            |
