## ۱. Executive Summary

این سند **معماری سیستم برند Xennic** را تعریف می‌کند. برند Xennic یک دارایی سازمانی است — نه یک هویت بصری ساده و نه یک کتابچه راهنمای بازاریابی.

سیستم برند Xennic چهار لایه دارد:

```
┌──────────────────────────────────────────────────────┐
│  لایه ۱: هویت (Identity)     ← Purpose, DNA, Values │
├──────────────────────────────────────────────────────┤
│  لایه ۲: بیان (Expression)   ← Voice, Tone, Language │
├──────────────────────────────────────────────────────┤
│  لایه ۳: تجسم (Visualization)← Philosophy of Design  │
├──────────────────────────────────────────────────────┤
│  لایه ۴: اجرا (Execution)    ← Rules for Human & AI  │
└──────────────────────────────────────────────────────┘
```

### اصول بنیادین

| اصل      | توضیح                                                    |
| -------- | -------------------------------------------------------- |
| **B-01** | برند یک دارایی سازمانی است — حفاظت از آن مسئولیت همه است |
| **B-02** | هویت برند در تمام خروجی‌ها یکپارچه و سازگار است          |
| **B-03** | قواعد برند برای انسان و Agent الزامی است                 |
| **B-04** | انحراف از برند فقط با تأیید مدیر برند مجاز است           |
| **B-05** | برند تابع قانون اساسی SMOS است                           |

این سند طبق [CON-000](../05-CONSTITUTION/00-constitution.md) §۱۶ (یکپارچگی برند) و [ARCH-001](../00-ARCHITECTURE/01-system-overview.md) §۱۲ (معماری پلتفرم) تعریف شده است.

## ۲. Brand Purpose

برند Xennic برای یک هدف مشخص وجود دارد:

**"توانمندسازی ارتباطات انسانی در عصر هوش مصنوعی."**

این هدف سه بعد دارد:

| بعد        | توضیح                                                                        |
| ---------- | ---------------------------------------------------------------------------- |
| **ارتباط** | هر فعالیت برند برای ایجاد ارتباط معناگرا بین Xennic و مخاطبانش طراحی شده است |
| **انسانی** | فناوری در خدمت انسان است، نه برعکس                                           |
| **آینده**  | برند به آینده‌ای تعلق دارد که در آن هوش مصنوعی و انسان همکاری می‌کنند        |

## ۵. Brand DNA

DNA برند Xennic از سه عنصر تشکیل شده است:

```
             ┌─────────────────────┐
             │        نور          │
             │     (روشن‌گری)      │
             └─────────────────────┘
                    │    ▲
                    ▼    │
   ┌─────────────────────┐─────────────────────┐
   │        نیرو         │        یکتا          │
   │     (تأثیرگذاری)    │─── (منحصربه‌فردی) ──│
   └─────────────────────┘─────────────────────┘
```

| عنصر      | فارسی | معنا                        | تجلی در برند                 |
| --------- | ----- | --------------------------- | ---------------------------- |
| **Noor**  | نور   | روشن‌گری، شفافیت، آگاهی     | محتوای آموزشی و ارزش‌آفرین   |
| **Niroo** | نیرو  | تأثیرگذاری، قدرت، انرژی     | محتوای متقاعدکننده و اثرگذار |
| **Yekta** | یکتا  | منحصربه‌فردی، اصالت، نوآوری | دیدگاه و سبک متمایز          |

این سه عنصر از نام شرکت (زر نور نیرو یکتا) مشتق شده‌اند و DNA تمام فعالیت‌های برند را شکل می‌دهند.

صدای برند Xennic **چیستی** و **چگونگی** بیان برند را تعریف می‌کند — نه **چه می‌گوییم**، بلکه **چگونه می‌گوییم**.

### ویژگی‌های صدا

| ویژگی         | توضیح                        | مثال (مفهومی)                 |
| ------------- | ---------------------------- | ----------------------------- |
| **آگاهانه**   | نشان‌دهنده دانش و تخصص       | توضیح عمیق با استدلال         |
| **صریح**      | مستقیم و بدون پیچیدگی مصنوعی | جملات کوتاه و مفهوم           |

| **الهام‌بخش** | ایجاد انگیزه برای تفکر       | پرسش‌های محرک ذهن             |
| **انسانی**    | گرمی و اصالت انسانی          | زبان طبیعی، نه ماشینی         |

### قواعد صدا

| قاعده    | توضیح                                                        |

## ۱۱. Brand Tone Matrix

لحن (Tone) بُعد متغیر برند است. لحن تابعی است از **مخاطب × زمینه × هدف**.

### ماتریس لحن

| بُعد                   | طیف                   | توضیح                 |
| ---------------------- | --------------------- | --------------------- |
| **رسمی ↔ غیررسمی**     | از رسمی تا دوستانه    | بسته به کانال و مخاطب |
| **جدی ↔ طنز**          | از جدی تا شوخ         | بسته به موضوع         |
| **فنی ↔ عمومی**        | از تخصصی تا همه‌فهم   | بسته به دانش مخاطب    |
| **ساختاریافته ↔ آزاد** | از منظم تا خلاق       | بسته به نوع محتوا     |
| **هیجانی ↔ منطقی**     | از احساسی تا استدلالی | بسته به هدف محتوا     |

### ماتریس زمینه‌ای

| زمینه         | لحن پیش‌فرض             | طیف مجاز                |
| ------------- | ----------------------- | ----------------------- |
| **آموزشی**    | رسمی + فنی + منطقی      | رسمی-غیررسمی، فنی-عمومی |
| **تبلیغاتی**  | غیررسمی + هیجانی + جسور | جدی-طنز، هیجانی-منطقی   |
| **پشتیبانی**  | رسمی + عمومی + گرم      | رسمی، غیررسمی ملایم     |
| **خبری**      | رسمی + منطقی + دقیق     | رسمی، نیمه‌رسمی         |
| **تعاملی**    | غیررسمی + گرم + دوستانه | غیررسمی، خلاق           |
| **بحرانی**    | رسمی + جدی + دقیق       | رسمی، محترمانه          |
| **الهام‌بخش** | آزاد + هیجانی + عمیق    | از نیمه‌رسمی تا رها     |

### قواعد لحن

| قاعده   | توضیح                                                                     |
| ------- | ------------------------------------------------------------------------- |
| TONE-01 | لحن با صدا تضاد ندارد                                                     |
| TONE-02 | هر محتوا یک لحن مسلط دارد (نه چند لحن متناقض)                             |
| TONE-03 | تغییر لحن تدریجی است — تغییر ناگهانی لحن ممنوع                            |
| TONE-04 | لحن در یک قطعه محتوا می‌تواند تغییر کند (مثلاً شروع جدی، پایان الهام‌بخش) |

## ۱۲. Brand Language

زبان برند Xennic مجموعه قواعد زبانی است که نحوه استفاده از کلمات، جملات و ساختارهای زبانی را تعریف می‌کند.

### اصول زبانی

| اصل             | توضیح                                                                        |
| --------------- | ---------------------------------------------------------------------------- |
| **فارسی اصیل**  | زبان رسمی فارسی با استفاده از معادل‌های فارسی برای اصطلاحات بیگانه           |
| **روان و ساده** | جملات کوتاه، ساختار ساده، اجتناب از حشو                                      |
| **دقیق**        | استفاده از واژگان [ARCH-003](../00-ARCHITECTURE/03-glossary.md) — بدون ابهام |
| **محترم**       | ضمایر محترمانه، لحن مودبانه                                                  |
| **شامل‌گرا**    | زبانی که همه مخاطبان را در بر می‌گیرد (بدون تبعیض جنسیتی، قومیتی)            |

### قواعد زبانی

| قاعده   | توضیح                                                                         |
| ------- | ----------------------------------------------------------------------------- |
| LANG-01 | از واژه‌های ممنوع [ARCH-003](../00-ARCHITECTURE/03-glossary.md) استفاده نکنید |
| LANG-02 | اختصارات در اولین استفاده توضیح داده شوند                                     |
| LANG-03 | اصطلاحات تخصصی با معادل فارسی + انگلیسی در پرانتز                             |
| LANG-04 | جملات خبری کوتاه (حداکثر ۲۵ کلمه)                                             |
| LANG-05 | فعل در پایان جمله — ساختار دستور زبان فارسی حفظ شود                           |

## ۱۳. Brand Philosophy

فلسفه برند Xennic چارچوب فکری پشت تمام تصمیمات برند است.

### اصول فلسفی

| اصل                | توضیح                                                           |
| ------------------ | --------------------------------------------------------------- |
| **انسان‌محوری**    | برند برای انسان است، نه برای فناوری                             |
| **ارزش‌آفرینی**    | هر تعامل با برند باید برای مخاطب ارزش ایجاد کند                 |
| **شفافیت رادیکال** | اطلاعات دقیق، منابع مشخص، بدون پنهان‌کاری                       |
| **پایداری**        | برند برای بلندمدت ساخته شده — نه برای لحظه                      |
| **تکامل**          | برند زنده است — تغییر می‌کند بدون اینکه هویت خود را از دست بدهد |

### فلسفه در عمل

| موقعیت    | رفتار برند                     |
| --------- | ------------------------------ |
| عدم قطعیت | شفاف‌سازی به جای سکوت          |
| خطا       | پذیرش و اصلاح به جای انکار     |
| رقابت     | تمرکز بر خود، نه تخریب رقیب    |
| نوآوری    | آزمایش جسورانه، ارائه مسئولانه |
| بحران     | پاسخ سریع، شفاف و مسئولانه     |

## ۱۴. Visual Philosophy

فلسفه بصری برند Xennic **چرایی** و **چگونگی** طراحی بصری را تعریف می‌کند — نه مشخصات دقیق.

### اصول بصری

| اصل             | توضیح                                                    |
| --------------- | -------------------------------------------------------- |
| **روشنایی**     | طراحی روشن، باز و قابل خواندن — تاریکی استثناست نه قاعده |
| **سادگی**       | minimalism هدف‌مند — فقط عناصر ضروری                     |
| **انسجام**      | همه عناصر بصری یک خانواده بصری واحد را تشکیل می‌دهند     |
| **هدفمندی**     | هر عنصر بصری دلیل وجودی دارد — تزئین بدون هدف ممنوع      |
| **دسترس‌پذیری** | طراحی برای همه — including افراد با محدودیت‌های بینایی   |

### قواعد فلسفه بصری

| قاعده       | توضیح                                                                          |
| ----------- | ------------------------------------------------------------------------------ |
| VIS-PHIL-01 | زیبایی در سادگی است — پیچیدگی غیرضروری ممنوع                                   |
| VIS-PHIL-02 | فضا عنصر طراحی است — از white space به عنوان عنصر فعال استفاده کنید            |
| VIS-PHIL-03 | سلسله‌مراتب بصری — مهم‌ترین عنصر بزرگ‌ترین و برجسته‌ترین است                   |
| VIS-PHIL-04 | سازگاری بین پلتفرم‌ها — مخاطب در همه جا Xennic را تشخیص دهد                    |
| VIS-PHIL-05 | هر دارایی بصری باید در بسترهای مختلف (موبایل، دسکتاپ، پرینت) قابل استفاده باشد |

## ۱۵. Color Philosophy

فلسفه رنگ برند Xennic **معنا و کاربرد** رنگ‌ها را تعریف می‌کند — نه کدهای دقیق.

### اصول رنگ

| اصل             | توضیح                                                                    |
| --------------- | ------------------------------------------------------------------------ |
| **معناگرایی**   | هر رنگ معنایی دارد و آن معنا در همه جا یکسان است                         |
| **تضاد هدفمند** | تضاد رنگی برای خوانایی و تأکید، نه برای تزئین                            |
| **پایداری**     | پالت رنگ محدود و کنترل‌شده — گسترش فقط با تأیید مدیر برند                |
| **دسترس‌پذیری** | کنتراست کافی برای خوانایی توسط همه مخاطبان                               |
| **سازگاری**     | رنگ‌ها در همه پلتفرم‌ها (دیجیتال و چاپ) تا حد ممکن یکسان نمایش داده شوند |

### کارکرد رنگ‌ها

| کارکرد        | توضیح                                      |
| ------------- | ------------------------------------------ |
| **رنگ اصلی**  | هویت برند — در لوگو، هدر، عناصر اصلی       |
| **رنگ مکمل**  | پشتیبانی از رنگ اصلی — در بخش‌های فرعی     |
| **رنگ تأکید** | برای Call-to-Action, لینک‌ها, عناصر تعاملی |

## ۲۳. Brand Governance

حکمرانی برند — چه کسی چه تصمیمی می‌گیرد.

### ماتریس مالکیت (برگرفته از [ARCH-030](../00-ARCHITECTURE/30-governance-architecture.md) §۴)

| نقش            | مسئولیت                                   |
| -------------- | ----------------------------------------- |
| **Owner**      | مدیر برند — پاسخگویی نهایی برای هویت برند |
| **Custodian**  | مدیر برند — مدیریت روزمره برند            |
| **Maintainer** | طراح برند — به‌روزرسانی دارایی‌های برند   |
| **Reviewer**   | مدیر محتوا — بازبینی تطابق محتوا با برند  |
| **Approver**   | مدیر برند — تأیید نهایی تغییرات برند      |
| **Consumer**   | همه — استفاده از برند در خروجی‌ها         |

### سطوح تصمیم برند

| سطح | نوع تصمیم                        | تأییدکننده              |
| --- | -------------------------------- | ----------------------- |
| L1  | استفاده از دارایی‌های برند موجود | Agent (خودکار)          |
| L2  | تغییر لحن در چارچوب مجاز         | مدیر محتوا              |
| L3  | تغییر دارایی برند                | مدیر برند + معمار سیستم |
| L4  | تغییر هویت برند                  | مدیر برند + مدیر ارشد   |
| L5  | تغییر فلسفه برند                 | مدیر ارشد (هیئت مدیره)  |

### فرایند تغییر برند

طبق [ARCH-031](../00-ARCHITECTURE/31-change-management.md):

```
Change Request → Impact Analysis (روی همه پلتفرم‌ها)
  → Review (توسط Reviewer) → Approval (توسط Approver)
    → Implementation → Validation → Versioning → Communication
```

## ۲۴. Brand Decision Principles

اصول تصمیم‌گیری برند.

### اصول

| اصل        | توضیح                                                       |
| ---------- | ----------------------------------------------------------- |
| **DEC-01** | هر تصمیم برند باید با Purpose, Mission و Vision سازگار باشد |
| **DEC-02** | هر تصمیم برند باید با DNA (نور، نیرو، یکتا) هماهنگ باشد     |
| **DEC-03** | منافع بلندمدت برند بر منافع کوتاه‌مدت اولویت دارد           |
| **DEC-04** | در تعارض، بالاترین سطح برند (Purpose) مقدم است              |
| **DEC-05** | هیچ تصمیم برندی بدون مستندسازی گرفته نمی‌شود                |

### چارچوب تصمیم

```
۱. آیا این تصمیم با Purpose برند سازگار است؟
۲. آیا این تصمیم با DNA برند هماهنگ است؟
۳. آیا این تصمیم ارزش‌های برند را نقض می‌کند؟
۴. تأثیر این تصمیم بر ادراک مخاطب چیست؟
۵. آیا این تصمیم برگشت‌پذیر است؟
۶. اگر به همه مخاطبان توضیح داده شود، قابل دفاع است؟
```
