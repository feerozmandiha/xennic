# مستندات SMOS

سیستم مستندات **Social Media Operating System (SMOS)** برای مدیریت شبکه‌های اجتماعی شرکت Xennic.

## شروع سریع

1. معماری حکمرانی: `docs/00-ARCHITECTURE/30-governance-architecture.md`
2. معماری متا: `docs/00-ARCHITECTURE/10-meta-architecture.md`
3. مدل اشیاء: `docs/00-ARCHITECTURE/11-object-model.md`
