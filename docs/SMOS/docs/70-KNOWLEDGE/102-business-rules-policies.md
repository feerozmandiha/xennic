## ۱. Purpose

KNW-102 تنها SSOT (تک منبع حقیقت) برای قوانین، سیاست‌ها و محدودیت‌های رسمی کسب‌وکار SMOS است.

### چرا KNW-102 وجود دارد

بدون یک SSOT برای قوانین کسب‌وکار:

- قوانین در اسناد مختلف پراکنده می‌شوند
- سیاست‌ها با یکدیگر تناقض پیدا می‌کنند
- محدودیت‌ها ناشناخته می‌مانند
- Agentها نمی‌توانند مرزهای عملیاتی را رعایت کنند
- انطباق (compliance) غیرقابل اندازه‌گیری است
- استثناها و ارجاع‌ها مسیر مشخصی ندارند

KNW-102 این مشکلات را با تعریف **چارچوب رسمی قوانین و سیاست‌های کسب‌وکار** حل می‌کند.

### نقش KNW-102 در SMOS

| سند         | نقش                                                   |
| ----------- | ----------------------------------------------------- |
| CON-000     | قانون اساسی — اصول عالی                               |
| KNW-101     | SSOT مفاهیم، موجودیت‌ها و قابلیت‌های کسب‌وکار         |
| **KNW-102** | **SSOT قوانین، سیاست‌ها و محدودیت‌های رسمی کسب‌وکار** |
| KNW-103     | SSOT فرآیندهای مرجع کسب‌وکار                          |

### رابطه با KNW-101

KNW-102 بر پایه KNW-101 ساخته می‌شود:

- از واژگان بنیادین KNW-101 (VOC-\*) استفاده می‌کند
- از موجودیت‌های KNW-101 (ENT-\*) به عنوان مرجع استفاده می‌کند
- از قابلیت‌های KNW-101 (CAP-\*) به عنوان دامنه استفاده می‌کند
- مفاهیم از پیش تعریف‌شده در KNW-101 را بازتعریف نمی‌کند
- فقط قوانین، سیاست‌ها و محدودیت‌ها را تعریف می‌کند

## ۳. Business Rule Philosophy

### فلسفه قاعده کسب‌وکار

SMOS قوانین کسب‌وکار را به عنوان **مرزهای عملیاتی سازمان** می‌بیند که:

1. **الزامی هستند** — اجرا یا نقض می‌شوند، پیشنهاد نیستند
2. **قابل اندازه‌گیری هستند** — انطباق با قانون قابل محاسبه است
3. **تغییرناپذیر هستند** — مگر با ADR یا مصوبه رسمی
4. **مستند هستند** — همه قوانین در KNW-102 ثبت می‌شوند
5. **قابل مصرف هستند** — توسط انسان و Agent قابل تفسیر یکسان

### اصول هستی‌شناسی قانون

| اصل                       | توضیح                          |
| ------------------------- | ------------------------------ |
| **قانون یک محدودیت است**  | دامنه اقدام را محدود می‌کند    |
| **قانون یک شرط دارد**     | در صورت شرط، قانون فعال می‌شود |
| **قانون یک نتیجه دارد**   | در صورت نقض، اقدام مشخص است    |
| **قانون یک مالک دارد**    | مسئول تفسیر و تغییر قانون      |
| **قانون قابل ردیابی است** | از تعریف تا اجرا               |
