## ۱. Purpose

KNW-501 نخستین سند خانواده AI Knowledge (KNW-AI) و SSOT (تک منبع حقیقت) برای تمام مفاهیم، دامنه‌ها، موجودیت‌ها، قابلیت‌ها و کارکردهای هوش مصنوعی سازمانی SMOS است.

### چرا KNW-501 وجود دارد

بدون یک پایه دانش هوش مصنوعی:

- مفاهیم هوش مصنوعی در AI-_ و PRM-_ پراکنده می‌شوند
- Agentها نمی‌توانند دانش هوش مصنوعی را به صورت ساختاریافته مصرف کنند
- قابلیت‌های هوش مصنوعی قابل ردیابی و مقایسه نیستند
- اضافه کردن قابلیت هوش مصنوعی جدید نیازمند بازتعریف مفاهیم است
- هماهنگی بین AI-_ و PRM-_ و KNW-\* مختل می‌شود
- معماری دانش هوش مصنوعی بدون مبنا باقی می‌ماند

KNW-501 این مشکلات را با تعریف **چارچوب یکپارچه دانش هوش مصنوعی** حل می‌کند.

### نقش KNW-501 در SMOS

## ۴. AI Philosophy

### فلسفه دانش هوش مصنوعی

SMOS دانش هوش مصنوعی را به عنوان **زبان مشترک هوش مصنوعی** سازمان می‌بیند که:

1. **انتزاعی است** — مستقل از هر مدل، ابزار یا Vendor خاصی تعریف می‌شود
2. **ثابت است** — در طول زمان پایدار می‌ماند مگر با ADR تغییر کند
3. **مرجع است** — همه AI-*ها و PRM-*ها به آن ارجاع می‌دهند
4. **قابل مصرف است** — توسط انسان و Agent قابل درک است
5. **تک منبع است** — هر مفهوم هوش مصنوعی یک خانه دارد
6. **عاملی است** — هوش مصنوعی SMOS مبتنی بر عامل‌های هوشمند است

### اصول هستی‌شناسی هوش مصنوعی

| اصل                                | توضیح                                                   |
| ---------------------------------- | ------------------------------------------------------- |
| **هوش مصنوعی یک عامل است**         | هر قابلیت هوش مصنوعی توسط یک Agent ارائه می‌شود         |
| **هر Agent یک قابلیت دارد**        | تمرکز Agent بر یک حوزه مشخص از قابلیت است               |
| **هر Agent یک وضعیت دارد**         | وضعیت جاری Agent قابل ردیابی است                        |
| **Agentها همکاری می‌کنند**         | Agentها برای دستیابی به اهداف سازمانی با هم کار می‌کنند |
| **Agent تابع دانش است**            | Agent از دانش سازمانی برای تصمیم‌گیری استفاده می‌کند    |
| **Agent از پرامپت استفاده می‌کند** | Agent با استفاده از پرامپت‌های تعریف‌شده عمل می‌کند     |
