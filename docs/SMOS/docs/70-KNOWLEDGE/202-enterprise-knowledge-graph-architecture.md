## ۱. Purpose

KNW-202 معماری گراف دانش سازمانی SMOS را تعریف می‌کند. این سند به عنوان **تک منبع حقیقت (SSOT)** برای بازنمایی ساختار یافته تمام روابط معنایی در اکوسیستم دانش سازمانی عمل می‌کند — بدون وابستگی به فناوری، فروشنده، پایگاه داده گراف یا زبان پرس‌وجو.

### Why KNW-202 Exists

بدون یک معماری گراف دانش سازمانی:

- روابط بین موجودیت‌های دانش در اسناد پراکنده مدفون می‌شوند
- ردیابی وابستگی‌های عرضی بین خانواده‌های دانش غیرممکن است
- قابلیت کشف دانش از طریق روابط معنایی از دست می‌رود
- تکامل دانش بدون درک تأثیر تغییر بر سایر دانش‌ها غیرممکن است
- تحلیل تأثیر (impact analysis) برای تغییرات دانش قابل اجرا نیست
- حکمرانی یکپارچه بر روابط دانش ناممکن است

KNW-202 این مشکلات را با تعریف یک **چارچوب گراف دانش سازمانی** حل می‌کند که همه موجودیت‌ها و روابط تعریف‌شده در تمام KNW-NNNها را به عنوان گره و یال می‌بیند.

## ۴. Graph Philosophy

### فلسفه گراف دانش سازمانی

SMOS گراف دانش را به عنوان **نقشه زنده از دانش سازمانی** می‌بیند که:

1. **جهانی است** — همه موجودیت‌های دانش در یک فضای گراف یکپارچه قابل بازنمایی هستند
2. **چندلایه است** — هر لایه جنبه خاصی از روابط دانش را بازنمایی می‌کند
3. **تکامل‌پذیر است** — گره‌ها و یال‌ها در طول زمان اضافه، تغییر و حذف می‌شوند
4. **اعتبارپذیر است** — هر رابطه دارای منشأ، مالک و اعتبار مشخص است
5. **خنثی است** — معماری گراف به هیچ فناوری، استاندارد یا فروشنده خاصی وابسته نیست

### تمایز گراف از سایر بازنمایی‌ها

| بازنمایی           | ویژگی                    | KNW-202                                    |
| ------------------ | ------------------------ | ------------------------------------------ |
| KNW-001 (نمایه)    | فهرست خطی دانش‌ها        | گراف روابط بین دانش‌ها را اضافه می‌کند     |
| KNW-000 (معماری)   | چارچوب مادر              | گراف لایه بازنمایی عملیاتی را تعریف می‌کند |
| KNW-201 (کامپایلر) | تبدیل خام به ساختاریافته | گراف خروجی کامپایلر را به هم متصل می‌کند   |
| پایگاه داده گراف   | ذخیره و بازیابی          | معماری — نه پیاده‌سازی                     |

### ماشین وضعیت گراف

```markdown
                    ┌──────────────┐
                    │   Defined    │
                    │  (تعریف‌شده) │
                    └──────┬───────┘
                           │ Connect
                           ▼

                           │ Validate

                    └──────┬───────┘
                           │ Activate
                           ▼
                    ┌──────────────┐
                    │   Active     │
                    │  (فعال)      │
                    └──────┬───────┘
                     ┌─────┴──────┐
                     │            │
                     ▼            ▼
               ┌──────────┐ ┌──────────┐
               │Deprecated│ │  Frozen  │
```
