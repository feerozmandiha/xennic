## ۱. Purpose

KNW-404 معماری گزارش‌دهی عملیاتی سازمانی SMOS است. این سند SSOT (تک منبع حقیقت) برای **تعریف اصول گزارش‌دهی، دامنه‌ها، تاکسونومی گزارش، طبقه‌بندی، مدل KPI عملیاتی، مدل معیارها، مدل داشبورد، مدل نشانگرها، چرخه حیات گزارش، حکمرانی گزارش‌دهی و رجیستری گزارش** برای همه موجودیت‌های عملیاتی تعریف‌شده در KNW-401 است.

### چرا KNW-404 وجود دارد

بدون یک معماری گزارش‌دهی عملیاتی:

- گزارش‌های عملیاتی بدون ساختار و ناهمگون تولید می‌شوند
- KPIهای عملیاتی تعریف رسمی و قابلیت مقایسه ندارند
- شاخص‌های عملکرد بدون واحد اندازه‌گیری و حد آستانه مشخص هستند
- داشبوردهای عملیاتی فاقد مدل یکپارچه و استاندارد هستند
- چرخه حیات گزارش‌ها بدون فرآیند مشخصی از ایجاد تا بایگانی دنبال می‌شود
- Agentها و مصرف‌کنندگان نمی‌توانند گزارش‌های معتبر و قابل مقایسه دریافت کنند

KNW-404 این مشکلات را با تعریف **چارچوب رسمی گزارش‌دهی عملیاتی** حل می‌کند.

## ۴. Reporting Philosophy

### فلسفه گزارش‌دهی عملیاتی

SMOS گزارش‌دهی عملیاتی را به عنوان **تبدیل داده به بینش قابل اقدام (Actionable Insight)** می‌بیند که:

1. **هدف‌مند است** — هر گزارش برای یک هدف مشخص و یک تصمیم‌گیرنده خاص طراحی می‌شود
2. **زنجیره‌ای است** — داده → اطلاعات → شاخص → بینش → تصمیم → اقدام
3. **قابل اعتماد است** — منشأ داده، روش محاسبه و خطای اندازه‌گیری مشخص است
4. **قابل اقدام است** — هر گزارش حاوی توصیه یا مسیر تصمیم‌گیری است
5. **تکامل‌پذیر است** — مدل گزارش‌دهی با بلوغ سازمانی بهبود می‌یابد

### اصول هستی‌شناسی گزارش

| اصل                             | توضیح                                                 |
| ------------------------------- | ----------------------------------------------------- |
| **هر شاخص یک منبع دارد**        | هر KPI و معیار دارای منبع داده مشخص است               |
| **هر معیار یک واحد دارد**       | همه معیارها دارای واحد اندازه‌گیری استاندارد هستند    |
| **هر شاخص یک حد آستانه دارد**   | محدوده قابل قبول برای هر شاخص تعریف شده است           |
| **هر گزارش یک مصرف‌کننده دارد** | هر گزارش برای حداقل یک نقش یا Agent طراحی شده است     |
| **هر داشبورد یک هدف دارد**      | هر داشبورد برای یک دامنه تصمیم‌گیری خاص طراحی شده است |

## ۹. Operational KPI Model

### مدل KPI عملیاتی

KPIهای عملیاتی SMOS دارای ساختار سلسله‌مراتبی سه‌سطحی هستند:

```
سطح ۱ — KPI استراتژیک (Strategic KPI)
  ↓
سطح ۲ — KPI عملیاتی (Operational KPI)
  ↓
سطح ۳ — KPI اجرایی (Execution KPI)
```

### ساختار مدل KPI

| سطح | مؤلفه           | تعداد | توضیح                                            |
| --- | --------------- | ----- | ------------------------------------------------ |
| ۱   | Strategic KPI   | ۶     | شاخص‌های کلان هم‌راستا با اهداف استراتژیک سازمان |
| ۲   | Operational KPI | ۱۲    | شاخص‌های میانی مرتبط با فرآیندهای عملیاتی        |
| ۳   | Execution KPI   | ۱۸    | شاخص‌های خرد مرتبط با وظایف و فعالیت‌های روزانه  |
