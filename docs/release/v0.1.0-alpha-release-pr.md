## بدنهٔ PR

### خلاصه

اولین Release از `dev` به `main`. این Release **پایهٔ استقرار Phase-0/Alpha** را به
شاخهٔ Production می‌آورد: پلتفرم با یک دستور روی یک سرور بالا می‌آید، مهاجرت‌ها خودکار
اعمال می‌شوند و داده‌های پایه seed می‌شوند. هیچ Push مستقیمی به `main` انجام نشده است.

### محتوای این Release

| حوزه         | تغییر                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------- |
| Governance   | سند مرجع Git/GitHub، Branch Ledger کامل ۱۵ شاخهٔ remote، سند Kickoff شاخهٔ توسعه                              |
| CI           | بستن Issue #4 — بازگرداندن baseline نصب `--frozen-lockfile` بدون هیچ bypass                                   |
| استقرار      | Dockerfile تولیدی برای API و Web، استک Compose یازده‌سرویسی، reverse proxy، اسکریپت `deploy.sh`، Runbook کامل |
| راستی‌آزمایی | گزارش استقرار واقعی با شواهد اجرا                                                                             |

### شواهد راستی‌آزمایی

مرجع: `docs/deployment/phase-0-alpha-verification-2026-08-16.md`

- **۱۱ سرویس از ۱۱ سرویس `healthy`** روی محیط واقعی (Docker + WSL2).
- **۱۱ مهاجرت Prisma** با موفقیت اعمال شد.
- **Seed کامل:** ۳ پلن، ۱۲ نقش، ۶۲ مجوز، ۷ تنظیم سیستمی، ۱۵ استاندارد مهندسی،
  ۷ ایجنت AI، ۷ فروشنده، ۳۸ محصول، ۱۶ feature flag، ادمین + Workspace «Xennic».
- **زمان build:** ~۹۷۴ ثانیه (cold) / ~۹ ثانیه (cache کامل).
- هیچ سرویس زیرساختی پورتی روی host منتشر نمی‌کند؛ تنها `nginx` روی ۸۰/۴۴۳.

### وضعیت Gateها

هر سه Gate روی `dev` سبز هستند: `CI`، `API E2E Gate`، `Release Gate`.

> توجه: Jobهای مرحلهٔ Release تنها با شرط `github.ref == 'refs/heads/main'` اجرا می‌شوند،
> بنابراین در PRهایی که مقصدشان `dev` است به‌صورت طراحی‌شده skip می‌شوند. در همین PR
> (مقصد `main`) برای نخستین بار به‌طور کامل اجرا خواهند شد.

### ریسک و بازگشت (Rollback)

| مورد                 | وضعیت                                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------------------------------- |
| تغییر Schema دیتابیس | ندارد — مهاجرت‌ها از قبل در `dev` بوده‌اند و در آزمون «No pending migrations» گزارش شد                     |

## دستور ساخت PR

```bash
gh pr create \
  --base main \
  --head dev \
  --title "release: v0.1.0-alpha — phase-0 platform baseline" \
  --body-file docs/release/v0.1.0-alpha-release-pr.md
```

> بدنه را از بخش «بدنهٔ PR» همین فایل بردارید (یا فایل را پیش از استفاده به همان بخش
> تقلیل دهید). Merge نهایی نیازمند Approve انسانی است؛ ruleset فعال
> `protect-main-and-dev` اجازهٔ Merge بدون PR و بدون بازبینی را نمی‌دهد.
