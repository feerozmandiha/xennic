## ۲. قواعد نرمال‌سازی متن (پیش از استخراج)

1. اعداد فارسی `۰۱۲۳۴۵۶۷۸۹` و عربی `٠١٢٣٤٥٦٧٨٩` → `0-9`.
2. `ي`→`ی`، `ك`→`ک`، حذف کشیده و کاراکترهای نامرئی.
3. حذف جداکننده هزارگان (`٬` و `,` بین ارقام) پیش از تبدیل عددی.
4. نیم‌فاصله (U+200C) و فاصله‌های چندگانه → فاصله واحد.
5. تاریخ‌های `1405/04/14` و `1405-04-14` یکسان‌سازی شوند.

## ۳. الگوهای استخراج (regex اصلی — پیاده‌سازی در `extract.ts`)

```text
شناسه قبض      → /شناسا?\s*قبض[:\s٫.]*\s*(\d{13})/
شناسه پرداخت   → /شناسا?\s*پرداخت[:\s٫.]*\s*(\d{13})/
مصرف           → /(?:مصرف|کارکرد)[^\d]{0,25}(\d{1,6})/  (نزدیک «کیلووات»)
دوره           → /از\s*(1[34]\d\d[\/\-.]\d\d[\/\-.]\d\d)\s*تا\s*(1[34]\d\d[\/\-.]\d\d[\/\-.]\d\d)/
روز            → /(\d{2,3})\s*روز/ یا «تعداد روز … (\d+)»
بهای انرژی     → /بهای\s*انرژی[^\d]{0,15}([\d٬,]+)/
جمع کل         → /(?:جمع\s*کل|مبلغ\s*قابل\s*پرداخت)[^\d]{0,15}([\d٬,]+)/
ارزش افزوده    → /ارزش\s*افزوده[^\d]{0,15}([\d٬,]+)/
تبصره ۱۴       → /تبصره\s*۱۴?14?[^\d]{0,15}([\d٬,]+)/
منطقه          → /گرمسیر\s*([۱-۴|1-4])/ در نبود → normal
```

## ۴. امتیاز اطمینان

- هر فیلد: `confidence = پایه(0.6 برای تطبیق regex) + 0.2 (سازگاری متقابل) + 0.2 (تأیید cross-check)`.
- سازگاری‌های متقابل: `curReading − prevReading ≈ consumptionKwh×multiplier` (تلورانس ۲٪)، `Σ ردیف‌ها ≈ totalRials` (تلورانس ۵٪)، `periodDays ≈ periodTo − periodFrom`.
- فیلد با اطمینان < 0.7 در جدول با ⚠️ نمایش داده می‌شود و دکمه اصلاح می‌گیرد.
- `confidence` خروجی vision-service (0..1) مستقیماً به‌عنوان اطمینان کل سند استفاده می‌شود.
