# ۰۲ — الزامات و سناریوی مکالمه

## ۱. الزامات عملکردی (FR)

### دریافت فایل (FR-1xx)

- **FR-101** ربات فایل `pdf/jpg/jpeg/png/webp` تا ۱۰MB را بپذیرد؛ فرمت‌های دیگر با پیام راهنما رد شوند.
- **FR-102** هم `document` و هم `photo` (عکس فشرده تلگرام) پشتیبانی شود.
- **FR-103** اگر فایل رمزدار/خرابه بود، پیام خطای محترمانه + راهنمای اسکن مجدد.
- **FR-104** یک کاربر هم‌زمان فقط یک قبض در حال پردازش داشته باشد (ارسال قبض جدید، قبلی را لغو می‌کند).

### استخراج و جدول (FR-2xx)

- **FR-201** استخراج فیلدهای جدول [سند ۰۴](./04-BILL-DATA-MODEL.md) با اولویت: vision-service ← OCR عمومی + استخراج محلی ← ورود دستی.
- **FR-202** خروجی به‌صورت **جدول «عنوان | مقدار»** در سه بخش: ① اطلاعات شناسه‌ای/مشترک ② قرائت و کارکرد ③ ریز مبالغ.
- **FR-203** اعداد با جداکننده هزارگان و واحد (ریال / کیلووات‌ساعت) نمایش داده شوند.
- **FR-204** فیلدهای با اطمینان پایین با ⚠️ علامت بخورند و دکمه «اصلاح این مورد» فعال شود (ورود دستی همان فیلد).
- **FR-205** دکمه «قبض جدید 🔄» در هر مرحله در دسترس باشد.

### تحلیل (FR-3xx)

- **FR-301** تعیین منطقه (عادی/گرمسیر۱–۴) از متن قبض؛ در نبود، پرسش از کاربر با دکمه‌های انتخابی.
- **FR-302** تعیین ماه‌های گرم/غیرگرم از بازه دوره قبض.
- **FR-303** محاسبه پلکانی بهای انرژی با جداول ۱۴۰۵ ([سند ۰۵](./05-TARIFF-ENGINE-1405.md)) و نمایش جدول پله‌ها.
- **FR-304** مقایسه مبلغ محاسبه‌شده با مبلغ روی قبض؛ انحراف > ۵٪ → هشدار شفاف.
- **FR-305** محاسبه وضعیت نسبت به الگو: زیر الگو / الگو تا ۱٫۵× / ۱٫۵× تا ۲٫۵× / بیش از ۲٫۵× (نرخ ۵ برابر هزینه تأمین).
- **FR-306** در صورت وجود داده اوج‌بار/کم‌باری: محاسبه جریمه/پاداش ساعات بار.
- **FR-307** تولید ≥ ۳ توصیه شخصی‌سازی‌شده با برآورد ریالی صرفه‌جویی.
- **FR-308** (اختیاری) غنی‌سازی متن تحلیل با LLM؛ در نبود/خطا، فقط خروجی قاعده‌محور.

### گزارش PDF (FR-4xx)

- **FR-401** دکمه «🖨 چاپ گزارش PDF» → تولید PDF شامل: سربرگ، جدول کامل، جدول پله‌ها، تحلیل و توصیه‌ها، سلب مسئولیت، QR/شناسه گزارش.
- **FR-402** نام فایل: `گزارش-قبض-{شناسه‌قبض یا کد کوتاه}-{تاریخ شمسی}.pdf`.

### مشاوره (FR-5xx)

- **FR-501** دکمه «🎧 درخواست مشاوره» → دو دکمه فرعی: «💬 پیام خصوصی» و «📞 تماس تلفنی».
- **FR-502** مسیر PV: دریافت نام + متن سؤال → ثبت → کد پیگیری → اطلاع به ادمین.
- **FR-503** مسیر تلفن: دریافت شماره (دکمه اشتراک تماس یا ورود دستی + اعتبارسنجی `09xxxxxxxxx`) + بازه زمانی ترجیحی → ثبت → کد پیگیری → اطلاع به ادمین.
- **FR-504** کاربر وضعیت درخواست خود را با `/status` ببیند.
- **FR-505** ادمین با `/requests` فهرست باز را ببیند و با دکمه «بسته شد» وضعیت را تغییر دهد.

### عمومی (FR-6xx)

- **FR-601** دستورها: `/start` `/help` `/bill` (شروع ارسال قبض) `/status` `/cancel`؛ برای ادمین: `/requests`.
- **FR-602** همه پیام‌ها فارسی، RTL، با ایموجی معنادار و حداکثر ۲–۳ خط.

## ۲. الزامات غیرعملکردی (NFR)

| کد    | الزام                                                                        |
| ----- | ---------------------------------------------------------------------------- |
| NFR-1 | زمان پاسخ تعاملی (به‌جز OCR) < ۲ ثانیه؛ پردازش کامل قبض < ۳۰ ثانیه (P95)     |
| NFR-2 | دسترس‌پذیری ≥ ۹۹٪ (long-polling با راه‌اندازی مجدد خودکار)                   |
| NFR-3 | پردازش ≥ ۱۰ قبض هم‌زمان بدون تداخل (صف هر پلتفرم مجزا)                       |
| NFR-4 | هیچ داده خام قبض بیش از ۲۴ ساعت نگهداری نشود مگر کاربر گزارش بخواهد (بخش ۰۸) |
| NFR-5 | لاگ ساختاریافته + متریک‌های Prometheus-سازگار (تعداد قبض، موفقیت OCR، خطاها) |
| NFR-6 | اجرا روی Node 22 بدون build؛ تست‌ها در CI < ۶۰ ثانیه                         |
| NFR-7 | تغییر تعرفه سالانه ≤ ۱ ساعت کاری (ویرایش داده + تست)                         |

## ۳. سناریوی مکالمه (Happy Path)

```
کاربر: /start
ربات:  سلام 👋 من ربات تحلیل قبض برق‌ام.
       قبض برقت رو به‌صورت «عکس» یا «PDF» بفرست تا:
       ۱) اطلاعاتش رو دقیق استخراج کنم
       ۲) بر اساس تعرفه ۱۴۰۵ تحلیلش کنم
       [📄 ارسال قبض]  [❓ راهنما]

کاربر: (عکس/PDF قبض)
ربات:  ⏳ در حال خواندن قبض… (معمولاً کمتر از ۳۰ ثانیه)
ربات:  ✅ اطلاعات استخراج شد — اطمینان: ۹۴٪
       ┌─ جدول اطلاعات شناسه‌ای ─…┐
       │ شناسه قبض   │ ۱۱۱۷۵۴۰۶۰۱۰۲۳ │
       │ نام مشترک   │ …            │
       │ دوره        │ ۱۴۰۵/۰۲/۱۵ تا ۱۴۰۵/۰۴/۱۴ (۶۱ روز) │
       └─ قرائت و کارکرد ─…
       │ شاخص قبلی/فعلی │ ۱۲۳۴۵ / ۱۲۶۱۰ │
       │ مصرف دوره      │ ۲۶۵ kWh        │
       └─ ریز مبالغ ─…
       │ بهای انرژی │ ۴٬۱۲۰٬۰۰۰ ریال │ …
       [🔍 تحلیل تعرفه] [✏️ اصلاح اطلاعات] [🔄 قبض جدید]

کاربر: (دکمه تحلیل یا خودکار پس از جدول)
ربات:  📊 تحلیل بر اساس تعرفه ۱۴۰۵ (منطقه عادی — ماه غیرگرم):
       ▫️ میانگین ماهانه: ۱۳۰ kWh — ✅ زیر الگوی مصرف (۳۰۰)
       ▫️ جدول پله‌ها: ۱۰۰×۱٬۹۳۵ + ۱۰۰×۲٬۲۵۳ + ۳۰×۴٬۸۳۸ ریال…
       ▫️ بررسی صحت: مبلغ محاسبه‌شده ≈ مبلغ قبض ✓
       ▫️ توصیه‌ها: ۱) … (−۲۱۰٬۰۰۰ ریال/دوره) ۲) … ۳) …
       [🖨 چاپ گزارش PDF] [🎧 درخواست مشاوره] [🔄 قبض جدید]

کاربر: دکمه «درخواست مشاوره»
ربات:  چه نوع مشاوره‌ای؟ [💬 پیام خصوصی] [📞 تماس تلفنی] [↩️ بازگشت]
کاربر: «تماس تلفنی»
ربات:  شماره تماس را بفرستید یا دکمه زیر را بزنید: [📱 ارسال شماره من]
کاربر: ۰۹۱۲…
ربات:  بازه ترجیحی تماس؟ [صبح ۹–۱۲] [ظهر ۱۲–۱۵] [عصر ۱۵–۱۸]
ربات:  ✅ درخواست شما ثبت شد. کد پیگیری: #A1B2C3
       کارشناسان ما در بازه انتخابی با شما تماس می‌گیرند.
```

## ۴. حالت‌های خطا و حاشیه‌ای

| حالت                         | رفتار                                                                                                               |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| OCR هیچ فیلد کلیدی پیدا نکرد | پیام «متأسفانه قبض خوانا نبود» + راهنمای عکس‌برداری (نور، زاویه، فاصله) + پیشنهاد «ورود دستی» شناسه قبض/کارکرد/مبلغ |
| نوع تعرفه غیرخانگی           | اطلاع «این قبض {تجاری/صنعتی/...} است؛ تحلیل کامل در نسخه بعدی» + نمایش جدول اطلاعات + ادامه با تحلیل عمومی          |
| انحراف محاسبه > ۵٪           | نمایش هر دو عدد + توضیح علل محتمل (تبصره‌ها، عوارض محلی، گردکردن) + ادامه جریان                                     |
| API پلتفرم خطا داد           | تلاش مجدد نمایی (۳ بار) + لاگ؛ اگر long-polling قطع شد، اتصال خودکار                                                |
| فایل > ۱۰MB                  | پیام محدودیت + پیشنهاد فشرده‌سازی                                                                                   |
