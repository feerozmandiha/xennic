# Knowledge Access Tiers

دانشنامهٔ تخصصی زنیک بر اساس سطح مخاطب به چهار دسته تقسیم می‌شود:

| Tier              | Slug         | دسترسی                                  |
| ----------------- | ------------ | --------------------------------------- |
| بسیار ساده        | `free`       | بدون ورود به حساب — عمومی و قابل ایندکس |
| متوسط             | `basic`      | هر کاربر واردشده (هر پلنی)              |
| تخصصی             | `pro`        | کاربران دارای پلن `pro` یا `enterprise` |
| فوق‌تخصصی/سازمانی | `enterprise` | فقط کاربران دارای پلن `enterprise`      |

## اصول

- مقالات `free` از مسیر `/public/knowledge` (بدون احراز هویت) و با SEO کامل سرو می‌شوند.
- مقالات `basic`, `pro`, `enterprise` از مسیرهای احراز هویت‌شده سرو می‌شوند و بسته به پلن کاربر فیلتر می‌شوند.
- فیلد `access_tier` به‌صورت مستقل از `difficulty` است تا سطح دسترسی و سطح آموزشی از هم جدا باشند.
- وقتی یک مشترک فعال منقضی می‌شود، دسترسی‌اش به `basic` تقلیل می‌یابد.
