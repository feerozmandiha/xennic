KEY DIFFERENCES FROM SOCIAL PLATFORM PLAYBOOKS
--------------------------------------------------------------------------------
  - Role Hub (P0): Highest priority in SMOS — all platforms serve it
  - Owned Platform: Full organizational control, no third-party dependency
  - No Social Engagement: No comments/likes/shares — focus on knowledge
  - Hashtag Strategy → Category/Tag System: Hierarchical organization
  - Caption Guidelines → Page Writing Guidelines: Title, Meta, H1-H6, Alt
  - Post Types → Page Types: 15 distinct page archetypes
  - Community Model → Readership Model: Public, no membership required
  - Engagement Model → Conversion Model: Focus on CTA and conversion
  - Widest AI Coverage: 13 of 14 SMOS agents interact with Website
  - Most Workflows: 9 workflows covering entire content lifecycle
  - 12 KPIs: Comprehensive measurement across SEO, content, knowledge
  - 33 CT-IDs: Almost all content types appear on Website
  - 9 Quality Gates: Most rigorous verification pipeline
  - Schema.org: Unique to Website — structured data for search engines
  - Core Web Vitals: Performance gate unique to owned platform

RISKS
--------------------------------------------------------------------------------
  R-01  Content Volume: Website requires highest content volume.
        Mitigation: AI-generated content (60%) with human oversight.

  R-02  SEO Competition: Ranking in competitive keywords is difficult.
        Mitigation: Long-tail strategy, content quality focus.

  R-03  Content Decay: Old content loses relevance and ranking.
        Mitigation: AUT-007-RFR (weekly refresh workflow).

  R-04  Technical Debt: Core Web Vitals degrade over time with changes.
        Mitigation: AUT-007-MON (daily monitoring).

  R-05  Brand Consistency: Large volume may dilute brand voice.
        Mitigation: AI-004 (Review) + Brand Gate for all content.

RECOMMENDATIONS
--------------------------------------------------------------------------------
  1. Prioritize SEO infrastructure (Schema.org, Core Web Vitals,
     Sitemap) before mass content production.

  2. Implement AUT-007-PUB workflow first — all other workflows
     depend on the publishing pipeline.

  3. Start with CT-001 (Educational Article) and CT-032 (Documentation)
     as initial content types — highest value-to-effort ratio.

  4. Set up Google Analytics + Search Console from day 0 — all 12 KPIs
     depend on measurement infrastructure.

  5. Establish Content Calendar for first 3 months before scaling to
     full automation.
