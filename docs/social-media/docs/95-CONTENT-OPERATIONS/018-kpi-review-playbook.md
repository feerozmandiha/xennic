> **شناسه:** OPS-018
> **نسخه:** 1.0.0-draft
> **تاریخ:** 2026-07-12
> **خانواده:** OPS-CONTENT
> **نوع:** عملیاتی — راهنمای بررسی روزانه/هفتگی/ماهانه شاخص‌های کلیدی عملکرد

## ۱. Purpose — هدف

این سند راهنمای عملیات روزانه, هفتگی و ماهانه بررسی شاخص‌های کلیدی عملکرد (KPI) محتوا در Xennic است. از بررسی روزانه داشبورد تا گزارش ماهانه و آماده‌سازی گزارش فصلی, تمام فرآیندها در این سند تعریف شده است.

این سند معماری نیست — دستورالعمل اجرای روزانه پایش عملکرد محتوا است.

## ۵. Daily KPI Review Workflow — جریان کار بررسی روزانه

### چک‌لیست بررسی روزانه (۱۵ دقیقه)

- [ ] داشبورد روزانه را باز کنید
- [ ] شاخص‌های کلیدی دیروز را بررسی کنید
- [ ] نسبت به روز قبل مقایسه کنید
- [ ] ناهنجاری‌ها (بیش از ±۲۰٪ تغییر) را شناسایی کنید
- [ ] محتوای برتر و ضعیف را شناسایی کنید
- [ ] نتایج را در لاگ ثبت کنید
- [ ] در صورت نیاز به مدیر عملیات اطلاع دهید

### تصمیم‌نامه بررسی روزانه

| وضعیت                   | اقدام                      |
| ----------------------- | -------------------------- |
| تمام شاخص‌ها در محدوده  | ثبت + ادامه                |
| یک شاخص خارج از محدوده  | بررسی علت + ثبت            |
| >۲ شاخص خارج از محدوده  | اطلاع‌رسانی به مدیر عملیات |
| شاخص بحرانی زیر ۵۰٪ هدف | اقدام فوری + جلسه          |

## ۸. Trend Identification — شناسایی روندها

### انواع روندها

| نوع روند   | توضیح              | بازه بررسی               |
| ---------- | ------------------ | ------------------------ |
| روند صعودی | افزایش پیوسته شاخص | ≥۳ هفته متوالی           |
| روند نزولی | کاهش پیوسته شاخص   | ≥۳ هفته متوالی           |
| روند فصلی  | تغییرات دوره‌ای    | مقایسه ماه مشابه سال قبل |
| روند ثبات  | بدون تغییر معنادار | ≥۴ هفته پایدار           |

### فرآیند شناسایی روند

```
جمع‌آوری داده ≥۳ هفته → ترسیم نمودار → شناسایی الگو → تأیید با مقایسه فصلی → ثبت روند → پیش‌بینی
```

### تصمیم‌نامه روند

| نوع روند     | اقدام                           |
| ------------ | ------------------------------- |
| صعودی (مثبت) | تقویت عوامل موفق + گزارش به تیم |
| نزولی (منفی) | تحلیل ریشه + اقدام اصلاحی       |
| فصلی         | برنامه‌ریزی برای دوره مشابه     |
| ثبات         | بررسی آیا هدف محقق شده          |

| -------------- | --------------------------- | ----------------------- |
| ناهنجاری بالا  | >+۵۰٪ تغییر نسبت به میانگین | افزایش ناگهانی Reach    |


| پایین (منفی) | بالا  | تحلیل فوری + اقدام اصلاحی |
