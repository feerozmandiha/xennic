## ۱. Purpose — هدف

این سند چک‌لیست گام‌به‌گام انتشار محتوا در Xennic است. از لحظه دریافت محتوای تأییدشده تا تأیید نهایی انتشار, هر مرحله فرآیند انتشار در این سند تعریف شده است.

این سند معماری نیست — دستورالعمل اجرای روزانه انتشار محتوا است.

## ۳. Publishing Workflow — جریان کار انتشار

### مراحل اصلی

```
دریافت محتوای تأییدشده → آماده‌سازی پلتفرمی → بررسی نهایی → انتشار → تأیید زنده → پایش → ثبت
```

### جدول مراحل

| مرحله       | ورودی                  | خروجی           | مسئول      | حداکثر زمان |
| ----------- | ---------------------- | --------------- | ---------- | ----------- |
| دریافت      | محتوای تأییدشده        | محتوای دریافتی  | مدیر تولید | ≤۱ ساعت     |
| آماده‌سازی  | محتوا + الزامات پلتفرم | نسخه پلتفرمی    | مدیر جوامع | ≤۲ ساعت     |
| بررسی نهایی | نسخه پلتفرمی           | تأیید/رد        | ویراستار   | ≤۱ ساعت     |
| انتشار      | محتوای تأییدشده        | محتوای منتشرشده | مدیر جوامه | طبق تقویم   |
| تأیید زنده  | محتوای منتشرشده        | تأیید نهایی     | مدیر جوامع | ≤۱۵ دقیقه   |
| پایش        | محتوای منتشرشده        | گزارش اولیه     | مدیر جوامع | ≤۳۰ دقیقه   |
| ثبت         | اطلاعات انتشار         | لاگ انتشار      | مدیر تولید | ≤۱۵ دقیقه   |

## ۴. Pre-Publishing Verification — تأیید پیش از انتشار

### چک‌لیست عمومی پیش از انتشار

- [ ] محتوا توسط مدیر عملیات تأیید نهایی شده
- [ ] فرم انتشار (این سند) تکمیل شده
- [ ] نسخه نهایی محتوا مشخص و ذخیره شده
- [ ] فایل‌های پیوست (تصاویر, ویدئو) آماده هستند
- [ ] زمان انتشار در تقویم تحریریه ثبت شده
- [ ] پلتفرم‌های هدف مشخص شده‌اند
- [ ] مسئول انتشار مشخص شده

### تصمیم‌نامه انتشار

| وضعیت               | اقدام                  |
| ------------------- | ---------------------- |
| همه موارد تأیید     | ادامه به مرحله بعد     |
| یک مورد جزئی ناقص   | اصلاح سریع + ادامه     |
| بیش از یک مورد ناقص | توقف + اصلاح + بازبینی |

## ۱۵. Error Detection & Rollback — شناسایی خطا و بازگشت

### انواع خطاهای پس از انتشار

| نوع خطا            | شدت   | اقدام                     |
| ------------------ | ----- | ------------------------- |
| املای اشتباه آشکار | متوسط | اصلاح در اولین فرصت       |
| لینک شکسته         | بالا  | اصلاح فوری                |
| اطلاعات نادرست     | حیاتی | حذف + اصلاح + انتشار مجدد |
| تصویر نامناسب      | بالا  | حذف + جایگزینی            |
| عدم انطباق حقوقی   | حیاتی | حذف فوری + مشورت حقوقی    |

### مراحل بازگشت (Rollback)

```
۱. شناسایی خطا → ۲. ارزیابی شدت → ۳. تصمیم حذف/اصلاح → ۴. اجرا → ۵. انتشار مجدد → ۶. ثبت در لاگ
```

### تصمیم‌نامه بازگشت

| شدت خطا | اقدام                          | حداکثر زمان |
| ------- | ------------------------------ | ----------- |
| حیاتی   | حذف فوری + اصلاح + انتشار مجدد | ≤۳۰ دقیقه   |
| بالا    | اصلاح + انتشار مجدد            | ≤۱ ساعت     |
| متوسط   | اصلاح در اولین فرصت            | ≤۴ ساعت     |
| پایین   | اصلاح در برنامه عادی           | ≤۲۴ ساعت    |
