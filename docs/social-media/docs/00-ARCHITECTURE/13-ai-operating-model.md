## ۱. معرفی

این سند **مدل عملیاتی عامل‌های هوشمند (AI Agents)** SMOS را تعریف می‌کند.
هر Agent یک واحد نرم‌افزاری با هدف، ورودی، خروجی، وابستگی، اختیار و محدودیت مشخص است.

## ۲. اصول معماری Agentها

1. **تک‌مسئولیتی** — هر Agent دقیقاً یک مسئولیت اصلی دارد
2. **ترکیب‌پذیری** — Agentها با هم ترکیب می‌شوند نه اینکه قابلیت‌ها را تکرار کنند
3. **انسان در حلقه** — تصمیمات کلیدی نیاز به تأیید انسانی دارند
4. **شفافیت** — هر Agent مسیر تصمیم خود را ثبت می‌کند
5. **محدودیت اختیار** — هر Agent مرزهای مشخصی دارد
6. **مستندات محور** — Agentها از مستندات به عنوان SSOT استفاده می‌کنند

## ۴. مشخصات عامل‌ها

### Agent-000: Orchestrator (هماهنگ‌کننده)

| فیلد        | مقدار                                                                       |
| ----------- | --------------------------------------------------------------------------- |
| **هدف**     | هماهنگی بین همه Agentها، مدیریت جریان کار، تصمیم‌گیری در مورد واگذاری وظایف |
| **ورودی**   | وظیفه از انسان یا workflow                                                  |
| **خروجی**   | برنامه اجرایی، وظایف واگذارشده به Agentها                                   |
| **وابستگی** | AI-\* (همه Agentها)                                                         |
| **اختیار**  | تصمیم‌گیری در مورد توالی و اولویت                                           |
| **محدودیت** | نمی‌تواند محتوا تولید یا تأیید کند                                          |
| **SSOT**    | [AI-005](../40-AI-AGENTS/50-orchestrator/)                                  |

### Agent-001: Research (تحقیق)

| فیلد        | مقدار                                                        |
| ----------- | ------------------------------------------------------------ |

## ۷. امنیت و محدودیت‌های Agentها

1. هیچ Agentی نمی‌تواند محتوا را بدون تأیید انسانی منتشر کند
2. هیچ Agentی نمی‌تواند قواعد برند را دور بزند
3. هیچ Agentی نمی‌تواند به حساب‌های کاربری خارج از محدوده دسترسی داشته باشد
4. همه Agentها مکلف به رعایت CON-000 هستند
5. همه Agentها باید منبع اطلاعات خود را اعلام کنند
6. هر Agent یک human-in-the-loop دارد
7. Agentها نمی‌توانند یکدیگر را ایجاد، حذف یا تغییر دهند
8. Orchestrator می‌تواند Agentها را فعال/غیرفعال کند
