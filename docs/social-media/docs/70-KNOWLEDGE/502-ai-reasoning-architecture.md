## ۱. Purpose

KNW-502 دومین سند خانواده AI Knowledge (KNW-AI) و SSOT (تک منبع حقیقت) برای معماری استدلال هوش مصنوعی سازمانی SMOS است.

### چرا KNW-502 وجود دارد

بدون یک معماری استدلال هوش مصنوعی:

- نحوه استدلال Agentها در AI-_ و PRM-_ پراکنده می‌شود
- الگوهای استدلال قابل مقایسه و ارزیابی نیستند
- کیفیت استدلال Agentها قابل اندازه‌گیری نیست
- اضافه کردن الگوی استدلال جدید نیازمند بازتعریف مفاهیم است
- زنجیره استدلال Agentها قابل ردیابی نیست
- هماهنگی بین Agentها در استدلال مختل می‌شود

KNW-502 این مشکلات را با تعریف **چارچوب یکپارچه معماری استدلال هوش مصنوعی** حل می‌کند.

### نقش KNW-502 در SMOS

| سند            | نقش                                              |
| -------------- | ------------------------------------------------ |
| KNW-501        | SSOT مفاهیم پایه هوش مصنوعی — مرجع بالادستی      |
| **KNW-502**    | **SSOT معماری استدلال هوش مصنوعی**               |

## ۴. Reasoning Philosophy

### فلسفه استدلال هوش مصنوعی

SMOS استدلال هوش مصنوعی را به عنوان **قلب تصمیم‌گیری عامل‌های هوشمند** می‌بیند که:

1. **ساختاری است** — استدلال از مراحل و الگوهای مشخص پیروی می‌کند
2. **شفاف است** — مسیر استدلال همیشه قابل مشاهده است
3. **مستند است** — هر استدلال دارای توضیح و توجیه است
4. **ارزیابی‌پذیر است** — کیفیت استدلال با معیارهای مشخص قابل اندازه‌گیری است
5. **انطباق‌پذیر است** — الگوهای استدلال با نیاز Agent تطبیق می‌یابند
6. **تکامل‌پذیر است** — الگوهای استدلال با یادگیری بهبود می‌یابند

### اصول هستی‌شناسی استدلال

| اصل                             | توضیح                                                     |
| ------------------------------- | --------------------------------------------------------- |
| **هر Agent استدلال می‌کند**     | هر عامل هوشمند برای تولید خروجی از استدلال استفاده می‌کند |
| **هر استدلال مسیر دارد**        | هر فرآیند استدلال دارای گام‌های مشخص است                  |
| **هر استدلال الگو دارد**        | هر استدلال از یک الگوی مشخص پیروی می‌کند                  |
| **استدلال تابع دانش است**       | کیفیت استدلال به دانش مصرفی وابسته است                    |
| **استدلال تابع بافت است**       | استدلال در بافت وظیفه و زمینه Agent انجام می‌شود          |
| **استدلال قابل اعتبارسنجی است** | نتیجه استدلال با معیارهای مشخص قابل ارزیابی است           |
