## ۱. Purpose

KNW-204 معماری پرس‌وجوی دانش سازمانی SMOS را تعریف می‌کند. این سند به عنوان **تک منبع حقیقت (SSOT)** برای چگونگی درخواست، کشف، تفکیک، فیلتر و بازیابی دانش سازمانی از گراف دانش (KNW-202) و موتور معنایی (KNW-203) عمل می‌کند — بدون وابستگی به فناوری، فروشنده، زبان پرس‌وجو، API یا الگوریتم.

### Why KNW-204 Exists

بدون یک معماری پرس‌وجوی دانش سازمانی:

- هر مصرف‌کننده دانش (Agent, سرویس, مؤلفه) مدل پرس‌وجوی خود را تعریف می‌کند
- مسیرهای کشف دانش پراکنده و ناسازگار می‌شوند
- تفکیک (Resolution) هویت‌ها و روابط بدون معماری یکپارچه غیرممکن است
- پیمایش گراف دانش بدون الگوی معماری مشخص انجام می‌شود
- اعتبارسنجی نتایج پرس‌وجو بدون چارچوب معماری تضمین نمی‌شود
- ترکیب پرس‌وجوهای چندمنبعی بدون چارچوب غیرممکن است

KNW-204 این مشکلات را با تعریف یک **چارچوب معماری پرس‌وجوی دانش سازمانی** حل می‌کند که یک مدل واحد و متعارف برای تمام پرس‌وجوهای آینده از Agentها، سرویس‌ها و مؤلفه‌ها ارائه می‌دهد.

## ۳. Knowledge Query Principles

| ID     | اصل                        | توضیح                                                        |
| ------ | -------------------------- | ------------------------------------------------------------ |
| KQP-01 | **Canonical Query**        | هر پرس‌وجوی دانش از یک مدل معماری واحد پیروی می‌کند          |
| KQP-02 | **Traceable Resolution**   | هر نتیجه پرس‌وجو قابل ردیابی به منبع دانش است                |
| KQP-03 | **Single Meaning**         | هر پرس‌وجو یک معنای متعارف دارد — ابهام در پرس‌وجو مجاز نیست |
| KQP-04 | **Deterministic Identity** | هویت درخواست‌شده در پرس‌وجو قطعی و بدون ابهام است            |
| KQP-05 | **Context Awareness**      | هر پرس‌وجو در یک بافت مشخص انجام می‌شود                      |
| KQP-06 | **Reference Integrity**    | ارجاعات در پرس‌وجو باید به موجودیت‌های معتبر منتهی شوند      |
| KQP-07 | **Minimal Ambiguity**      | پرس‌وجو باید کمترین ابهام ممکن را داشته باشد                 |
| KQP-08 | **Knowledge Independence** | مدل پرس‌وجو از مخزن دانش مستقل است                           |

## ۴. Knowledge Query Philosophy

### فلسفه پرس‌وجوی دانش سازمانی

SMOS پرس‌وجوی دانش را به عنوان **فرآیند معماری کشف و بازیابی دانش سازمانی** می‌بیند که:

1. **کانونیکال است** — همه پرس‌وجوها از یک مدل معماری واحد پیروی می‌کنند
2. **چندمرحله‌ای است** — هر پرس‌وجو از ۸ مرحله معماری عبور می‌کند
3. **بدون وضعیت است** — خود پرس‌وجو دارای وضعیت نیست — وضعیت در گراف دانش است
4. **قابل ردیابی است** — هر نتیجه پرس‌وجو تا منبع اصلی قابل ردیابی است
5. **خنثی است** — معماری پرس‌وجو به هیچ فناوری، زبان یا فروشنده خاصی وابسته نیست

### تمایز از سایر مؤلفه‌ها

| مؤلفه                | ویژگی            | KNW-204                                          |
| -------------------- | ---------------- | ------------------------------------------------ |
| KNW-202 (گراف)       | بازنمایی روابط   | پرس‌وجو بر روی گراف دانش اجرا می‌شود             |
| KNW-203 (معنایی)     | تفسیر معنا       | پرس‌وجو می‌تواند از سرویس‌های معنایی استفاده کند |
| AI-011 (مدیریت دانش) | عامل مدیریت دانش | مصرف‌کننده اصلی معماری پرس‌وجو                   |
| AI-014 (هماهنگ‌ساز)  | هماهنگ‌سازی      | مسیریابی درخواست‌های پرس‌وجو                     |
| پایگاه داده (ذخیره)  | ذخیره و بازیابی  | معماری — نه پیاده‌سازی                           |
| زبان پرس‌وجو (SQL)   | نحو و اجرا       | معماری — نه نحو                                  |

## ۲۹. Knowledge Query Integrity Rules

### قواعد یکپارچگی پرس‌وجو

| ID      | قاعده                        | توضیح                                  | منبع     |
| ------- | ---------------------------- | -------------------------------------- | -------- |
| QINT-01 | هر پرس‌وجو یک قصد دارد       | پرس‌وجوهای بدون قصد مجاز نیستند        | KQCST-01 |
| QINT-02 | هر هدف یک هویت دارد          | اهداف بدون هویت مشخص مجاز نیستند       | KQCST-02 |
| QINT-03 | هر نتیجه قابل ردیابی است     | نتایج باید رد کامل تا منبع داشته باشند | KQCST-04 |
| QINT-04 | بدون ابهام در قصد            | قصد پرس‌وجو باید unambiguous باشد      | KQCST-05 |
| QINT-05 | بدون پرس‌وجوی خارج از دامنه  | پرس‌وجو نباید از دامنه مجاز خارج شود   | KQCST-03 |
| QINT-06 | بدون نتیجه تکراری            | یک پرس‌وجو نتایج تکراری تولید نمی‌کند  | QCS-05   |
| QINT-07 | بدون پرس‌وجوی بی‌هدف         | هر پرس‌وجو به یک هدف مشخص منتهی می‌شود | QCS-07   |
| QINT-08 | عدم بازتعریف موجودیت‌های KNW | KNW-204 تنها ارجاع می‌دهد              | KQCST-06 |

## ۳۰. Cross-Domain Knowledge Query Mapping

### نگاشت پرس‌وجو بین دامنه‌های دانش

| دامنه مبدأ            | دامنه مقصد            | نوع نگاشت  | توضیح                                    |
| --------------------- | --------------------- | ---------- | ---------------------------------------- |
| KQD-01 (Discovery)    | KQD-02 (Resolution)   | Direct     | کشف دانش به تفکیک مسیر منتهی می‌شود      |
| KQD-02 (Resolution)   | KQD-03 (Navigation)   | Direct     | تفکیک به پیمایش گراف منتهی می‌شود        |
| KQD-03 (Navigation)   | KQD-06 (Relationship) | Contextual | پیمایش از طریق روابط انجام می‌شود        |
| KQD-04 (Filtering)    | KQD-08 (Consumption)  | Direct     | فیلتر قبل از تحویل اعمال می‌شود          |
| KQD-05 (Context)      | KQD-01 (Discovery)    | Contextual | بافت بر کشف تأثیر می‌گذارد               |
| KQD-06 (Relationship) | KQD-07 (Validation)   | Composite  | روابط توسط اعتبارسنجی تأیید می‌شوند      |
| KQD-07 (Validation)   | KQD-08 (Consumption)  | Direct     | نتایج معتبر به مصرف‌کننده تحویل می‌شوند  |
| KQD-08 (Consumption)  | KQD-01 (Discovery)    | Delegated  | مصرف می‌تواند به پرس‌وجوی جدید منتهی شود |
