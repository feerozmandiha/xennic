## ۱. Purpose

KNW-504 چهارمین سند خانواده AI Knowledge (KNW-AI) و SSOT (تک منبع حقیقت) برای معماری ابزار هوش مصنوعی سازمانی SMOS است.

### چرا KNW-504 وجود دارد

بدون یک معماری ابزار هوش مصنوعی:

- نحوه تعریف و مصرف ابزار توسط Agentها در AI-_ و PRM-_ پراکنده می‌شود
- الگوهای معماری ابزار قابل مقایسه و ارزیابی نیستند
- قابلیت ابزارها قابل اندازه‌گیری و مقایسه نیست
- اضافه کردن ابزار جدید نیازمند بازتعریف مفاهیم است
- انتخاب ابزار توسط Agent بدون معماری مشخص انجام می‌شود
- ترکیب ابزارها بدون ساختار معماری باقی می‌ماند
- چرخه حیات ابزار قابل ردیابی نیست

KNW-504 این مشکلات را با تعریف **چارچوب یکپارچه معماری ابزار هوش مصنوعی** حل می‌کند.

## ۴. Tool Philosophy

### فلسفه ابزار هوش مصنوعی

SMOS ابزار هوش مصنوعی را به عنوان **قابلیت اجرایی عامل‌های هوشمند** می‌بیند که:

1. **انتزاعی است** — مستقل از هر پیاده‌سازی فنی تعریف می‌شود
2. **قراردادی است** — هر ابزار دارای ورودی، خروجی و رفتار مشخص است
3. **قابل ترکیب است** — ابزارها می‌توانند برای اهداف بزرگتر ترکیب شوند
4. **قابل انتخاب است** — Agent می‌تواند بر اساس معیارها ابزار مناسب را انتخاب کند
5. **قابل مشاهده است** — همه ابزارها قابل ردیابی و نظارت هستند
6. **قابل جایگزینی است** — پیاده‌سازی ابزار بدون تغییر قرارداد قابل جایگزینی است

### اصول هستی‌شناسی ابزار

| اصل                                  | توضیح                                                     |
| ------------------------------------ | --------------------------------------------------------- |
| **هر Agent می‌تواند ابزار مصرف کند** | هر عامل هوشمند می‌تواند از ابزارهای تعریف‌شده استفاده کند |
| **هر ابزار یک قرارداد دارد**         | هر ابزار دارای ورودی، خروجی و خطاهای مشخص است             |
| **هر ابزار یک نوع دارد**             | هر ابزار از یک الگوی معماری مشخص پیروی می‌کند             |
| **ابزار تابع حافظه است**             | ابزار می‌تواند به حافظه Agent دسترسی داشته باشد           |
| **ابزار تابع استدلال است**           | انتخاب ابزار بر اساس استدلال Agent انجام می‌شود           |
| **ابزار تابع حکمرانی است**           | استفاده از ابزار با قواعد سازمانی محدود می‌شود            |
