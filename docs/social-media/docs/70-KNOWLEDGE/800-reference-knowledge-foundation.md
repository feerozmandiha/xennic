## 1. Purpose

KNW-801 نخستین سند خانواده Reference Knowledge (KNW-REF) و SSOT (تک منبع حقیقت) برای تمام مفاهیم مرجع، طبقه‌بندی‌ها، شناسه‌ها، شمارش‌ها و اشیاء مرجع سازمانی SMOS است که در سراسر خانواده‌های دانش قابل استفاده مجدد هستند.

### Why KNW-801 Exists

بدون یک پایه دانش مرجع:

- طبقه‌بندی‌های مشترک در هر خانواده دانش بازتعریف می‌شوند
- شناسه‌های یکسان با فرمت‌های متفاوت در اسناد مختلف ظاهر می‌شوند
- شمارش‌های استاندارد (مانند سطوح اختیار، وضعیت‌ها، اولویت‌ها) فاقد منبع واحد هستند
- واژگان کنترل‌شده قابل ردیابی و اعتبارسنجی نیستند
- هماهنگی بین خانواده‌های دانش نیازمند تطبیق دستی است
- تکامل شناسه‌ها و طبقه‌بندی‌ها بدون فرآیند مشخص باقی می‌ماند

KNW-801 این مشکلات را با تعریف **چارچوب یکپارچه دانش مرجع سازمانی** حل می‌کند.

## 4. Reference Philosophy

### فلسفه دانش مرجع

SMOS دانش مرجع را به عنوان **زبان مشترک بین‌خانواده‌ای** می‌بیند که:

1. **توصیف‌گر است** — ساختارها و طبقه‌بندی‌ها را توصیف می‌کند نه محتوای اجرایی
2. **انتزاعی است** — مستقل از هر خانواده دانش خاص تعریف می‌شود
3. **ثابت است** — در طول زمان تغییر نمی‌کند مگر با فرآیند حکمرانی سطح A-4
4. **مرجع است** — همه خانواده‌های دانش به آن ارجاع می‌دهند
5. **قابل مصرف است** — توسط انسان و Agent بدون ابهام قابل درک است
6. **ترکیب‌پذیر است** — طبقه‌بندی‌ها و شناسه‌ها قابل ترکیب و توسعه هستند

### هستی‌شناسی مرجع

دانش مرجع در SMOS دارای سه لایه هستی‌شناختی است:

| لایه             | توضیح                                      | مثال                                                 |
| ---------------- | ------------------------------------------ | ---------------------------------------------------- |
| Core (هسته)      | اصول و ساختارهای تغییرناپذیر مرجع          | Naming Rules, Identifier Format, Canonical Types     |
| Shared (مشترک)   | طبقه‌بندی‌ها و شمارش‌های قابل استفاده مجدد | Status Enumeration, Priority Levels, Severity Matrix |
| Extended (گسترش) | الحاقات و محلی‌سازی برای خانواده‌های خاص   | Domain-specific Classifications, Localized Values    |

## 12. Reference Taxonomy

### طبقه‌بندی دانش مرجع

دانش مرجع SMOS در سه سطح طبقه‌بندی می‌شود:

| سطح      | شناسه          | توضیح                                                        | دامنه‌ها |
| -------- | -------------- | ------------------------------------------------------------ | -------- |
| Core     | RFD-01..RFD-04 | طبقه‌بندی، تاکسونومی، شمارش و شناسه — هسته تغییرناپذیر       |
| Shared   | RFD-05, RFD-06 | نمایه و مقادیر بنیادین — قابل استفاده مجدد در همه خانواده‌ها |
| Extended | RFD-07, RFD-08 | بومی‌سازی و یکپارچگی — الحاقات وابسته به بافت                |

### اصول طبقه‌بندی

1. هر مفهوم مرجع دقیقاً در یک دامنه طبقه‌بندی می‌شود
2. دامنه‌های Core بالاترین اولویت را در ارجاع دارند
3. دامنه‌های Shared قواعد دامنه‌های Core را گسترش می‌دهند
4. دامنه‌های Extended محلی‌سازی و یکپارچگی را مدیریت می‌کنند

## 16. Reference Consistency Model

### مدل سازگاری مرجع

سازگاری دانش مرجع در SMOS در چهار بعد تعریف می‌شود:

| بعد                      | توضیح                                                                   | معیار                                         |
| ------------------------ | ----------------------------------------------------------------------- | --------------------------------------------- |
| Semantic Consistency     | سازگاری معنایی — یک مفهوم در همه خانواده‌ها یکسان معنا دارد             | همه خانواده‌ها از تعریف یکسان استفاده می‌کنند |
