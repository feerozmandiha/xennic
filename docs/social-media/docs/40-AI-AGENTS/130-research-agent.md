## ۱. Purpose

AI-001 نخستین عامل هوشمند SMOS و **منبع حقیقت واحد (SSOT)** برای تمام فعالیت‌های پژوهش، کشف دانش و گردآوری اطلاعات است.

این سند معماری عامل Research را بدون هیچ وابستگی به مدل زبانی، API، فروشنده یا فناوری خاص تعریف می‌کند. AI-001 به‌عنوان لایه اولیه زنجیره تولید محتوا، مواد خام اطلاعاتی را برای سایر Agentها و انسان‌ها فراهم می‌کند.

### جایگاه در معماری SMOS

AI-001 در **لایه دانش** (Knowledge Layer) معماری ARCH-012 قرار دارد. خروجی آن توسط AI-002 (Planning) برای برنامه‌ریزی محتوا، AI-003 (Writing) برای نگارش، و AI-005 (Fact Check) برای راستی‌آزمایی مصرف می‌شود.

```
INPUT LAYER    →    RESEARCH LAYER    →    PLANNING LAYER
(KNW, Web)          AI-001 (Research)      AI-002 (Planning)
                         ↓
                    WRITING LAYER
                    AI-003 (Writing)
                         ↓
                    REVIEW LAYER
                    AI-004 (Review) / AI-005 (Fact Check)
```

AI-001 به‌عنوان SSOT پژوهش، هیچ‌گاه به‌تنهایی تصمیم به استفاده از یک منبع نمی‌گیرد — فقط منابع را کشف، ارزیابی و ارائه می‌کند.

## ۷. Reasoning Model

AI-001 از یک مدل استدلال **چندمرحله‌ای** پیروی می‌کند:

### مرحله ۱ — فهمش (Framing)

درک موضوع تحقیق، محدوده، هدف و مخاطب.

- ورودی: IN-001 تا IN-008
- خروجی: چارچوب تحقیق (Research Frame)
- معیار موفقیت: تعریف دقیق مرزهای تحقیق

### مرحله ۲ — برنامه‌ریزی تحقیق (Research Planning)

تعیین روش تحقیق، منابع هدف، توالی جستجو.

- ورودی: Research Frame
- خروجی: Research Plan
- معیار موفقیت: پوشش کامل ابعاد موضوع

### مرحله ۳ — اجرا (Execution)

جستجو و گردآوری اطلاعات از منابع تعیین‌شده.

- ورودی: Research Plan
- خروجی: Raw Collection
- معیار موفقیت: گردآوری اطلاعات کافی برای تحلیل

### مرحله ۴ — ارزیابی (Evaluation)

بررسی اعتبار، دقت و relevance اطلاعات گردآوری‌شده.

- ورودی: Raw Collection
- خروجی: Validated Collection
- معیار موفقیت: حذف اطلاعات نامعتبر یا نامرتبط

### مرحله ۵ — تحلیل (Analysis)

شناسایی الگوها، روابط، شکاف‌ها و بینش‌ها.

- ورودی: Validated Collection
- خروجی: Analysis Result
- معیار موفقیت: استخراج حداقل ۳ بینش قابل اقدام

### مرحله ۶ — بسته‌بندی (Packaging)

ساخت Research Package نهایی مطابق استاندارد OUT-001.

- ورودی: Analysis Result
- خروجی: Research Package
- معیار موفقیت: تمام ۵ بخش بسته کامل است

### مرحله ۷ — خودارزیابی (Self-Assessment)

ارزیابی کیفیت و اطمینان تحقیق خود.

- ورودی: Research Package
- خروجی: Confidence Assessment
- معیار موفقیت: اطمینان اعلام‌شده با واقعیت مطابقت دارد

## ۸. Research Lifecycle

چرخه کامل پژوهش در AI-001 شامل ۸ فاز است:

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 1. Request │──▶│ 2. Frame │──▶│ 3. Plan  │──▶│ 4. Collect│
│ (دریافت)   │    │ (چارچوب) │    │ (برنامه) │    │ (گردآوری)│
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                      │
                                                      ▼
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 8. Archive│◀──│ 7. Package│◀──│ 6. Analyze│◀──│ 5. Evaluate│
│ (بایگانی) │    │ (بسته‌بندی)│    │ (تحلیل)  │    │ (ارزیابی) │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### فاز ۱ — Request

دریافت درخواست تحقیق از انسان یا Orchestrator.

### فاز ۲ — Frame

تعریف چارچوب تحقیق، محدوده، سوالات کلیدی.

### فاز ۳ — Plan

تعیین منابع، روش‌ها، توالی و زمان‌بندی.

### فاز ۴ — Collect

گردآوری اطلاعات از منابع تعیین‌شده.

### فاز ۵ — Evaluate

ارزیابی اعتبار، دقت و relevance.

### فاز ۶ — Analyze

تحلیل اطلاعات، شناسایی الگوها و بینش‌ها.

### فاز ۷ — Package

ساخت و تحویل Research Package.

### فاز ۸ — Archive

بایگانی تحقیق برای استفاده مجدد و یادگیری.

در هر فاز، AI-001 ممکن است به فاز قبلی بازگردد (loop) اگر اطلاعات کافی نباشد.

## ۹. Confidence Model

AI-001 از یک مدل اطمینان **چهارسطحی** برای هر خروجی استفاده می‌کند:

### سطوح اطمینان

| سطح     | مقدار     | توضیح                                          | اقدام                    |
| ------- | --------- | ---------------------------------------------- | ------------------------ |
| **C-4** | ۰٫۹۵-۱٫۰  | یقین — اطلاعات از منابع داخلی SSOT تأییدشده    | استفاده مستقیم           |
| **C-3** | ۰٫۸۰-۰٫۹۴ | اطمینان بالا — اطلاعات از چند منبع معتبر خارجی | قابل استفاده با ذکر منبع |
| **C-2** | ۰٫۶۰-۰٫۷۹ | اطمینان متوسط — اطلاعات از یک منبع معتبر       | نیاز به تأیید AI-005     |
| **C-1** | ۰٫۰۰-۰٫۵۹ | اطمینان کم — اطلاعات تأییدنشده یا حدسی         | ارسال به Escalation      |

### عوامل مؤثر بر اطمینان

| عامل                             | وزن |
| -------------------------------- | --- |
| تعداد منابع تأییدکننده           | ۳۰٪ |
| اعتبار منابع (Credibility Score) | ۲۵٪ |
| تطابق با دانش موجود KNW-\*       | ۲۰٪ |
| روشنی و عدم ابهام اطلاعات        | ۱۵٪ |
| قدمت اطلاعات (تازگی)             | ۱۰٪ |

### قواعد اطمینان

1. هر Research Package باید اطمینان کلی و اطمینان هر بخش را اعلام کند
2. اگر اطمینان کلی < ۰٫۶۰ باشد، بسته به Escalation می‌رود
3. AI-001 نمی‌تواند اطمینان یک منبع را بدون مستندات افزایش دهد
4. اطمینان C-1 به‌معنای «غیرقابل استفاده بدون تأیید انسانی» است
5. اطمینان C-4 فقط برای اطلاعاتی قابل استناد است که از SSOT داخلی و تأییدشده باشند

## ۱۱. Authority Level

بر اساس **ARCH-032**، AI-001 در سطح اختیار **A-1** (پیشنهاد به انسان) طبقه‌بندی می‌شود:

| بعد               | مقدار                                                                          |
| ----------------- | ------------------------------------------------------------------------------ |
| **سطح اختیار**    | A-1 — پیشنهاد به انسان                                                         |
| **نوع اقدام**     | ACT-002                                                                        |
| **دامنه تصمیم**   | انتخاب منابع و روش تحقیق                                                       |
| **نیاز به تأیید** | بسته پژوهشی نهایی نیاز به تأیید ندارد، اما ادعاهای با اطمینان < C-3 نیاز دارند |
| **محدودیت اصلی**  | نمی‌تواند نتیجه را تأیید شده اعلام کند                                         |

| --------------------- | --------------------------------------- |

| **Consistency Error** | Cross-verify → Escalate                 |
| **Timeout Error**     | Deliver partial → Log → Escalate        |
| **Input Error**       | Reject → Notify                         |
| **Permission Error**  | Escalate → Wait → Skip                  |
| **Scope Error**       | Escalate → Wait → Cancel                |
